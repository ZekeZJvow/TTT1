## 📌 产品简介

A股人气雷达 是一款**单机部署、免登录、免安装**的 A 股复盘工具，覆盖「人气榜 → 题材热度 → 首板选股 → 数据回看」全链条。

### 核心功能

- ✅ **📊 人气榜查询**：一键获取同花顺Top30人气股，含连板数/梯队/概念标签/异动解读，支持历史回看
- ✅ **🎯 动态选股**：输入交易日，扫描"昨日未涨停+盘中冲高>9%"的首板启动股池，出漏斗图与报告
- ✅ **🔥 题材热度**：自动发现当日利好题材（事件驱动+人气排序），给出利好原因与相关个股 Top50
- ✅ **🗄️ 数据管理**：本地数据仓库，按日查看/校验/清理/导出，支持人气榜历史回补
- ✅ **📈 个股详情**：分时线、日K线（按前收盘算涨幅）、近期资讯
- ✅ **降级机制**：多数据源保障可用性

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 网络连接

### 桌面应用（推荐）

双击桌面上的 **A股人气雷达** 图标即可（自动启动服务 + 打开应用窗口）。
已配置每天 8:00 自动启动，详见 [桌面应用与定时任务](docs/09-桌面应用与定时任务.md)。

### 安装步骤

`ash
# 1. 进入项目目录
cd stock-popularity

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python server.py
`

### 访问页面

浏览器打开：http://localhost:5000
