## 📌 产品简介

A股人气榜查询系统是一款**单机部署、手动查询**的股票数据分析工具，帮助用户快速获取同花顺个股人气榜Top30数据，配合可视化图表辅助投资决策。

### 核心功能

- ✅ **人气榜查询**：一键获取同花顺Top30人气股数据
- ✅ **K线图表**：分时线、日K线可视化展示
- ✅ **智能筛选**：按概念、涨停、排名多维度筛选
- ✅ **个股公告**：查看近期公司公告
- ✅ **降级机制**：多数据源保障可用性

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 网络连接

### 安装步骤

`ash
# 1. 进入项目目录
cd stock-popularity

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python server.py
`

### 访问页面

浏览器打开：http://localhost:5000
