## 一、这个模块做什么

把每天的三个市场情绪指标放在一起看，支持按月份回看：

| 指标 | 含义 | 口径 |
|---|---|---|
| **行情评分** | 当日**封板率** = 封住涨停 / 入选池 × 100 | 沪深主板**非ST**（与「动态选股」同一套规则） |
| **上涨 / 下跌家数** | 当日涨跌家数 | **沪深京全部A股**（含 ST/创业板/科创板/北交所，与同花顺「涨跌分布」完全一致） |
| **成交额总计 / 较上一日** | 两市成交额 + 相对上一交易日的增量/缩量 | 沪市 + 深市（上证综指 + 深证综指成交额） |

展示形式：顶部摘要 → 双轴走势图（橙线=评分，红绿柱=涨跌家数）→ 明细表（8 列，含成交额与较上一日）。
筛选：**1月~12月 月份按钮**（有数据才可点）+ 近30天/近60天/全部。

### 选股口径（封板率怎么算）

```
前收盘 → 涨停价 = 前收盘 × 1.1（四舍五入到分）
入选池 = 昨日「未触及涨停价」 且 今日「盘中最高涨幅 > 9%」
封住   = 今日收盘 ≥ 今日涨停价
封板率 = 封住 / 入选池 × 100
```
> 该反推法已与真实选股结果逐位核对一致。

## 三、数据流

```
                    ┌── 东方财富行情列表(6000+只) ─→ market_breadth   (涨跌家数，实时口径)
每日抓取 ───────────┤
                    └── 东方财富指数日K + 新浪实时 ─→ market_turnover (两市成交额)
本地日K(daily_kline) ──离线计算封板率──→ market_seal_stats (每日评分/涨跌家数)
                                              │
GET /api/market-history ──读 3 张小表 + 合并 ──┘ ─→ 前端图表 + 明细表
```

**性能设计（重要）**：本地日K有 100 多万行（库 270MB），直接按需计算要 11 秒。
所以把「封板率」离线算好写进 `market_seal_stats`（每天只增量算缺的日子，约 0.1 秒），
接口只读 199 行的小表 → **响应 0.01 秒**；另有 120 秒读缓存 + 启动预热。

## 四、表结构

```sql
market_seal_stats(trade_date PK, up_count, down_count, flat_count,
                  final_count, sealed_count, score, src, computed_at)
market_breadth   (trade_date PK, up_count, down_count, flat_count,
                  total_count, suspended, source, collected_at)
market_turnover  (trade_date PK, sh_amount, sz_amount, amount, source, collected_at)
索引：ix_k_date_pct ON daily_kline(trade_date, change_pct)   -- 覆盖索引，统计快 50 倍
```

## 五、接口

```
GET /api/market-history?days=45                     # 最近 45 个交易日
GET /api/market-history?start=2026-04-01&end=2026-04-30   # 指定区间（月份按钮用这个）
```
返回：`{success, days, start, end, count, months:[可用月份], rows:[{date, up, down, flat,
final, sealed, score, src, breadth_src, amount, amount_prev, amount_diff}]}`

## 六、依赖的第三方接口（都是公开接口，免登录免 Key）

| 用途 | 接口 |
|---|---|
| 历史涨跌家数口径的全市场列表 | `push2.eastmoney.com/api/qt/clist/get`（分页 60 次拉全市场） |
| 两市成交额（历史） | `push2his.eastmoney.com/api/qt/stock/kline/get`（1.000001 沪 + 0.399106 深） |
| 两市成交额（实时） | `hq.sinajs.cn/list=sh000001,sz399106` |
| 个股日K（补齐用） | `quotes.sina.cn/cn/api/jsonp_v2.php/…getKLineData` |

## 七、复刻需要注意的坑

1. **成分口径别搞错**：涨跌家数必须用「沪深京全部A股」，只统计主板会少一半（同花顺对不上）。
2. **ST 过滤**：封板率必须是「主板非ST」；数据库里要保留股票名称或 `is_st` 标记，
   且日K落库时**不能把名称覆盖成 NULL**（本项目踩过这个坑，导致评分虚高）。
3. **涨停价四舍五入**要用十进制/整数运算，浮点 `round()` 会在个别价位差 1 分。
4. **计算别放在请求里**：离线算好落库，接口只读小表，否则大库上会卡 10 秒以上。

## 文件：02_前端_逻辑.js

```javascript
// ==================== 模块5：行情评分走势 ====================
let mhChart = null;
let mhLoaded = false;

let mhStart = '';      // 日期范围（留空 = 不限）
let mhEnd = '';
let mhMonth = null;    // 当前选中的月份（1~12；null = 未选）
let mhLatest = '';     // 最新有数据的交易日（用于确定年份）
let mhHasMonths = {};   // 有数据的月份集合（默认全景视图下统计，兜底用）
let mhMonthsAvail = null;  // 服务端返回的「有数据的月份」（YYYY-MM）

function mhPad(v) { return (v < 10 ? '0' : '') + v; }

function mhYear() {
    // 用「最新有数据的交易日」所在年份
    return mhLatest ? Number(mhLatest.slice(0, 4)) : new Date().getFullYear();
}

function mhLastDay(y, m) {
    // m: 1~12 -> 该月最后一天
    return new Date(y, m, 0).getDate();
}

function mhBuildMonths() {
    const box = document.getElementById('mh-months');
    if (!box || box.childElementCount) return;
    let html = '';
    for (let k = 1; k <= 12; k++) {
        html += '<button class="mini-btn mh-month-btn" id="mh-m' + k + '"' +
            ' onclick="mhPickMonth(' + k + ')">' + k + '月</button>';
    }
    box.innerHTML = html;
}

function mhSyncMonthUI() {
    const y = mhYear();
    for (let k = 1; k <= 12; k++) {
        const el = document.getElementById('mh-m' + k);
        if (!el) continue;
        const ym = y + '-' + mhPad(k);
        const has = mhMonthsAvail ? !!mhMonthsAvail[ym] : !!mhHasMonths[k];
        el.classList.toggle('active', mhMonth === k);
        el.disabled = !has;
        el.classList.toggle('mh-month-empty', !has);
        el.title = has ? (y + '年' + k + '月') : (y + '年' + k + '月（本地暂无数据，可跑历史补齐）');
    }
}

function mhPickMonth(k) {
    mhBuildMonths();
    if (mhMonth === k) {            // 再点一次 = 取消，回到默认（近 45 天）
        mhMonth = null; mhStart = ''; mhEnd = '';
        mhSyncMonthUI();
        loadMarketHistory(true);
        return;
    }
    const y = mhYear();
    mhMonth = k;
    mhStart = y + '-' + mhPad(k) + '-01';
    mhEnd = y + '-' + mhPad(k) + '-' + mhPad(mhLastDay(y, k));
    mhSyncMonthUI();
    loadMarketHistory(true);
}

function mhQuickRange(n) {
    // 以「最新有数据的交易日」为终点，往前推 n 个自然日
    fetch('/api/market-history?days=1').then(function (x) { return x.json(); }).then(function (r) {
        const last = (r && r.success && r.rows && r.rows.length) ? r.rows[r.rows.length - 1].date : null;
        if (!last) return;
        const d = new Date(last + 'T00:00:00');
        d.setDate(d.getDate() - n);
        mhStart = d.getFullYear() + '-' + mhPad(d.getMonth() + 1) + '-' + mhPad(d.getDate());
        mhEnd = last;
        mhMonth = null;
        mhLatest = last;
        mhSyncMonthUI();
        loadMarketHistory(true);
    });
}

function mhResetRange() {
    mhStart = ''; mhEnd = ''; mhMonth = null;
    mhSyncMonthUI();
    loadMarketHistory(true);
}

async function loadMarketHistory(force) {
    if (mhLoaded && !force) return;
    mhBuildMonths();
    mhSyncMonthUI();
    const body = document.getElementById('mh-body');
    if (body) body.innerHTML = '<tr><td colspan="8" class="empty-cell">正在统计…</td></tr>';
    let r;
    try {
        let _u = '/api/market-history?days=45';
        if (mhStart) _u += '&start=' + encodeURIComponent(mhStart);
        if (mhEnd) _u += '&end=' + encodeURIComponent(mhEnd);
        r = await (await fetch(_u)).json();
    } catch (e) {
        if (body) body.innerHTML = '<tr><td colspan="8" class="empty-cell">加载失败：' + escHtml(e.message) + '</td></tr>';
        return;
    }
    if (!r || !r.success) {
        if (body) body.innerHTML = '<tr><td colspan="8" class="empty-cell">' + escHtml((r && r.error) || '暂无数据') + '</td></tr>';
        return;
    }
    mhLoaded = true;
    if (r.months && r.months.length) {
        mhMonthsAvail = {};
        for (let i = 0; i < r.months.length; i++) mhMonthsAvail[r.months[i]] = true;
    }
    renderMarketHistory(r.rows || []);
}

function fmtMhAmount(v) {
    // 成交额（亿元）-> 1.68万亿 / 8966亿
    if (v === null || v === undefined || v === '') return '—';
    const n = Number(v);
    if (!isFinite(n)) return '—';
    return Math.abs(n) >= 10000 ? (n / 10000).toFixed(2) + '万亿' : Math.round(n) + '亿';
}

function fmtMhDiff(v) {
    // 较上一日 -> 增量 +1382亿 / 缩量 -1382亿
    if (v === null || v === undefined || v === '') return '—';
    const n = Number(v);
    if (!isFinite(n)) return '—';
    const a = Math.abs(n);
    const txt = a >= 10000 ? (a / 10000).toFixed(2) + '万亿' : Math.round(a) + '亿';
    return (n >= 0 ? '增量 +' : '缩量 -') + txt;
}

function mhDiffCls(v) {
    if (v === null || v === undefined || v === '') return 'dim';
    const n = Number(v);
    if (!isFinite(n) || n === 0) return 'dim';
    return n > 0 ? 'up' : 'down';
}

function renderMarketHistory(rows) {
    const body = document.getElementById('mh-body');
    const sum = document.getElementById('mh-summary');
    if (!rows.length) {
        if (body) body.innerHTML = '<tr><td colspan="8" class="empty-cell">该日期范围内暂无数据</td></tr>';
        if (sum) sum.innerHTML = '<span class="mh-item dim">该日期范围内暂无数据</span>';
        if (mhChart) mhChart.clear();
        return;
    }
    const last = rows[rows.length - 1];
    if (last && last.date) {
        mhLatest = last.date;
    }
    if (!mhStart && !mhEnd) {
        // 默认全景视图 -> 记下哪些月份有数据（没数据的月份按钮置灰）
        const has = {};
        for (let i = 0; i < rows.length; i++) {
            const m = Number(String(rows[i].date).slice(5, 7));
            if (m) has[m] = true;
        }
        mhHasMonths = has;
    }
    if (last && last.date) {
        mhBuildMonths();
        mhSyncMonthUI();
    }
    if (sum) {
        sum.innerHTML =
            '<span class="mh-item">最新交易日 <b>' + escHtml(last.date) + '</b></span>' +
            '<span class="mh-item">行情评分 <b class="' + (last.score == null ? '' : (last.score >= 70 ? 'up-strong' : (last.score >= 50 ? 'mid' : 'down'))) + '">' +
                (last.score == null ? '--' : last.score) + '</b></span>' +
            '<span class="mh-item">上涨 <b class="up">' + last.up + '</b></span>' +
            '<span class="mh-item">下跌 <b class="down">' + last.down + '</b></span>' +
            '<span class="mh-item">成交额 <b class="up-strong">' + fmtMhAmount(last.amount) + '</b></span>' +
            '<span class="mh-item">较上一日 <b class="' + mhDiffCls(last.amount_diff) + '">' +
                fmtMhDiff(last.amount_diff) + '</b></span>' +
            '<span class="mh-item dim">共 ' + rows.length + ' 个交易日' +
                (mhMonth ? '（' + mhYear() + '年' + mhMonth + '月）'
                         : (mhStart || mhEnd ? '（' + (mhStart || '最早') + ' ~ ' + (mhEnd || '最新') + '）' : '')) +
                '</span>';
    }
    if (body) {
        body.innerHTML = rows.slice().reverse().map(function (x) {
            const cls = (x.score == null) ? 'dim' : (x.score >= 70 ? 'up-strong' : (x.score >= 50 ? 'mid' : 'down'));
            const ratio = x.down ? (x.up / x.down).toFixed(2) : '—';
            return '<tr>' +
                '<td>' + escHtml(x.date) + '</td>' +
                '<td class="num ' + cls + '">' + (x.score == null ? '—' : x.score) + '</td>' +
                '<td class="num up">' + x.up + '</td>' +
                '<td class="num down">' + x.down + '</td>' +
                '<td class="num dim">' + x.flat + '</td>' +
                '<td class="num dim">' + ratio + '</td>' +
                '<td class="num up-strong">' + fmtMhAmount(x.amount) + '</td>' +
                '<td class="num ' + mhDiffCls(x.amount_diff) + '">' + fmtMhDiff(x.amount_diff) + '</td>' +
                '</tr>';
        }).join('');
    }
    const box = document.getElementById('mh-chart');
    if (!box) return;
    if (!mhChart) mhChart = echarts.init(box);
    mhChart.setOption({
        backgroundColor: 'transparent',
        tooltip: {
            trigger: 'axis',
            backgroundColor: 'rgba(26,26,46,0.95)', borderColor: '#444',
            textStyle: { color: '#fff', fontSize: 13 },
            // 让提示框以「竖向虚线」为中心：水平居中于鼠标，并夹紧在图表内
            position: function (pt, params, dom, rect, size) {
                const w = (size && size.contentSize && size.contentSize[0]) || 0;
                const vw = (size && size.viewSize && size.viewSize[0]) || 0;
                let left = pt[0] - w / 2;
                const maxL = vw - w - 4;
                if (left < 4) left = 4;
                if (left > maxL) left = maxL;
                return [left, 8];
            },
            formatter: function (ps) {
                if (!ps || !ps.length) return '';
                const x = rows[ps[0].dataIndex] || {};
                return '<b>' + escHtml(x.date || '') + '</b>' +
                    '<br>行情评分：' + (x.score == null ? '—' : x.score) +
                    '<br>上涨家数：' + x.up +
                    '<br>下跌家数：' + x.down +
                    '<br>成交额总计：' + fmtMhAmount(x.amount) +
                    '<br>较上一日：' + fmtMhDiff(x.amount_diff);
            }
        },
        legend: { data: ['行情评分', '上涨家数', '下跌家数'], textStyle: { color: '#a0a0a0' }, top: 4 },
        grid: { left: 56, right: 64, top: 46, bottom: 58 },
        xAxis: {
            type: 'category', data: rows.map(function (x) { return x.date.slice(5); }),
            // z 调高：把竖向虚线画在柱子上层，否则会被柱子压住、看着像"没对准"
            axisPointer: {
                z: 120, snap: true,
                lineStyle: { color: 'rgba(255,255,255,0.8)', width: 1.2, type: 'dashed' }
            },
            axisLabel: { color: '#9aa0a6', fontSize: 11 }, axisLine: { lineStyle: { color: '#444' } }
        },
        yAxis: [
            { type: 'value', name: '评分', min: 0, max: 100, nameTextStyle: { color: '#9aa0a6' },
              axisLabel: { color: '#9aa0a6' }, splitLine: { lineStyle: { color: 'rgba(255,255,255,.06)' } } },
            { type: 'value', name: '家数', nameTextStyle: { color: '#9aa0a6' },

        ],
        series: [

    });
}

_STATS_CACHE = {"ts": 0.0, "n": 0, "rows": []}

EPS_LIMIT = 0.001          # 涨停价比较容差


def _limit_price(prev_close):
    """前收盘 -> 涨停价（×1.1 四舍五入到分）

    用整数运算实现（与 Decimal ROUND_HALF_UP 版逐位一致，已用全库 116 万条收盘价核对）。
    """
    return ((int(round(prev_close * 1000)) * 11 + 50) // 100) / 100.0


def invalidate_market_stats():

def compute_seal_stats(lookback_days=460, force=False, progress=None):
    """离线计算「每日封板率」并落库到 market_seal_stats（只算缺的日子）

    口径 = 沪深主板非ST：
        · 入选池 = 昨日未触及涨停价 且 今日盘中最高涨幅 > 9%
        · 封住   = 今日收盘 >= 今日涨停价（前收盘 × 1.1，四舍五入到分）
        · 行情评分 = 封板率 = 封住 / 入选池 × 100
    返回本次新算的天数。
    """
    import datetime as _dt
    n_done = [0]

    def _f(conn):
        cur = conn.cursor()
        since = (_dt.datetime.now() - _dt.timedelta(days=int(lookback_days))).strftime("%Y-%m-%d")
        # ① 最近每日行数 -> 完整交易日（当日有涨跌幅的股票 >= 2000 只）
        rows = conn.execute(
            "SELECT `trade_date`, COUNT(*) FROM `daily_kline` "
            "WHERE `trade_date` >= ? AND `change_pct` IS NOT NULL "
            "GROUP BY `trade_date`", (since,)).fetchall()
        complete = sorted(str(r[0]) for r in rows if (r[1] or 0) >= 2000)
        if len(complete) < 3:
            return 0
        pos = {d: i for i, d in enumerate(complete)}

        # ② 已算过的日子
        have = set()
        if not force:
            for r in conn.execute(
                    "SELECT `trade_date` FROM `market_seal_stats` WHERE `trade_date` >= ?",
                    (since,)).fetchall():
                have.add(str(r[0]))
        todo = [d for d in complete if pos[d] >= 2 and (force or d not in have)]
        if not todo:
            return 0

        # ③ ST 名单（评分口径 = 沪深主板非ST）
        st_codes = set()
        for r in conn.execute("SELECT `code`,`is_st`,`name` FROM `stock`").fetchall():
            nm = (r["name"] or "").upper().replace(" ", "")
            if r["is_st"] or ("ST" in nm):
                st_codes.add(clean_code(r["code"]))

        day_sql = ("SELECT k.`stock_code`, k.`high`, k.`close`, "
                   "k1.`high`, k1.`close`, k2.`close` "
                   "FROM `daily_kline` k "
                   "JOIN `daily_kline` k1 ON k1.`stock_code`=k.`stock_code` AND k1.`trade_date`=? "
                   "JOIN `daily_kline` k2 ON k2.`stock_code`=k.`stock_code` AND k2.`trade_date`=? "
                   "WHERE k.`trade_date`=? AND substr(k.`stock_code`,1,3) IN "
                   "('600','601','603','605','000','001','002','003')")
        upsert = _upsert("market_seal_stats",
                         ["trade_date", "up_count", "down_count", "flat_count",
                          "final_count", "sealed_count", "score", "src", "computed_at"],
                         ["trade_date"],
                         ["up_count", "down_count", "flat_count",
                          "final_count", "sealed_count", "score", "src", "computed_at"])
        ts = now_str()
        for d in todo:
            i = pos[d]
            d1, d2 = complete[i - 1], complete[i - 2]
            final = sealed = 0
            for r in conn.execute(day_sql, (d1, d2, d)).fetchall():
                code_, hi, cl, h1, c1, c2 = r[0], r[1], r[2], r[3], r[4], r[5]
                if code_ in st_codes:                  # 非 ST（与动态选股一致）
                    continue
                if not c1 or not c2 or not hi or h1 is None:
                    continue
                if h1 >= _limit_price(c2) - EPS_LIMIT:  # 昨日触及涨停 -> 剔除
                    continue
                if (hi - c1) / c1 > 0.09:               # 今日盘中冲高 > 9%
                    final += 1
                    if cl is not None and cl >= _limit_price(c1) - EPS_LIMIT:
                        sealed += 1
            agg = conn.execute(
                "SELECT SUM(`change_pct` > 0), SUM(`change_pct` < 0), SUM(`change_pct` = 0) "
                "FROM `daily_kline` WHERE `trade_date`=? AND `change_pct` IS NOT NULL",
                (d,)).fetchone()
            up = int(agg[0] or 0) if agg else 0
            down = int(agg[1] or 0) if agg else 0
            flat = int(agg[2] or 0) if agg else 0
            score = round(sealed / final * 100, 1) if final else None
            cur.execute(upsert, (d, up, down, flat, final, sealed, score, "kline", ts))
            n_done[0] += 1
            if progress:
                try:
                    progress(d, score)
                except Exception:
                    pass
        return n_done[0]

    out = _write(_f)
    if out:
        invalidate_market_stats()
    return out or 0


def ensure_seal_stats_async(min_interval=600.0):
    """若封板率统计落后于最新日K，后台补算（不阻塞页面）"""
    now = time.time()
    if _SEAL_STATE["running"] or (now - _SEAL_STATE["last_try"]) < min_interval:
        return False
    try:
        latest_k = _read(lambda c: c.execute("SELECT MAX(`trade_date`) FROM `daily_kline`").fetchone()[0], None)
        latest_s = _read(lambda c: c.execute("SELECT MAX(`trade_date`) FROM `market_seal_stats`").fetchone()[0], None)
    except Exception:
        return False
    if not latest_k:
        return False
    if latest_s and str(latest_s) >= str(latest_k):
        return False
    _SEAL_STATE["last_try"] = now
    _SEAL_STATE["running"] = True

    def _run():
        try:
            compute_seal_stats()
        except Exception:
            pass
        finally:
            _SEAL_STATE["running"] = False
    threading.Thread(target=_run, name="seal-stats", daemon=True).start()
    return True


def daily_market_stats(max_days=45, prefer_screening=True):
    """按日行情统计（读 market_seal_stats，秒出；带 120 秒缓存）

    返回 [{date, up, down, flat, final, sealed, score, src, breadth_src,
            amount, amount_prev, amount_diff}]（升序，最多 max_days 天）

    · 涨跌家数：优先用 market_breadth（实时抓取，沪深京全部A股口径，与同花顺一致），
                否则用离线统计里按本地日K算出的全市场家数
    · 行情评分：离线统计的封板率；若该日有真实选股结果则用真实值（更权威）
    """
    n = int(max_days)
    if prefer_screening:
        c = _STATS_CACHE
        if c["rows"] and c["n"] >= n and (time.time() - c["ts"]) < _STATS_TTL:
            return c["rows"][-n:]

    def _f(conn):
        head = conn.execute(
            "SELECT `trade_date`,`up_count`,`down_count`,`flat_count`,"
            "`final_count`,`sealed_count`,`score`,`src` FROM `market_seal_stats` "
            "ORDER BY `trade_date` DESC LIMIT ?", (n + 3,)).fetchall()
        if not head:
            return []
        rows = list(reversed(head))

        # 涨跌家数（实时抓取值优先）
        bmap = {}
        try:
            for r in conn.execute(
                    "SELECT `trade_date`,`up_count`,`down_count`,`flat_count` "
                    "FROM `market_breadth`").fetchall():
                bmap[r["trade_date"]] = (r["up_count"], r["down_count"], r["flat_count"])
        except Exception:
            bmap = {}
        # 两市成交额
        tmap = {}
        try:
            for r in conn.execute(
                    "SELECT `trade_date`,`amount` FROM `market_turnover`").fetchall():
                if r["amount"] is not None:
                    tmap[r["trade_date"]] = float(r["amount"])
        except Exception:
            tmap = {}
        # 真实选股结果（更权威）
        real = {}
        if prefer_screening:
            try:
                for r in conn.execute("SELECT target_date, payload_json FROM screening_run").fetchall():
                    try:
                        dd = json.loads(r["payload_json"])
                        if dd.get("success") and dd.get("sealedRate") is not None:
                            real[r["target_date"]] = float(dd["sealedRate"])
                    except Exception:
                        pass
            except Exception:
                real = {}

        out = []
        prev_amt = None
        for r in rows:
            d = str(r["trade_date"])
            up, down, flat = r["up_count"], r["down_count"], r["flat_count"]
            final, sealed = r["final_count"] or 0, r["sealed_count"] or 0
            bsrc = "kline"
            if d in bmap and bmap[d][0] is not None:
                up, down, flat = bmap[d][0], bmap[d][1], bmap[d][2]
                bsrc = "breadth"
            score, src = r["score"], r["src"] or "kline"
            if d in real:
                score = round(real[d], 1)
                src = "screening"
            amt = tmap.get(d)
            diff = (round(amt - prev_amt, 2)
                    if (amt is not None and prev_amt is not None) else None)
            prev_amt = amt if amt is not None else prev_amt
            out.append({"date": d, "up": up, "down": down, "flat": flat,
                        "final": final, "sealed": sealed, "score": score, "src": src,
                        "breadth_src": bsrc, "amount": amt, "amount_prev": None,
                        "amount_diff": diff})
        return out[-n:]
    rows = _read(_f, []) or []
    if not rows:
        # 首次使用（统计表还空着）-> 现算一次，保证页面有内容
        try:
            compute_seal_stats()
        except Exception:
            pass
        rows = _read(_f, []) or []
    if prefer_screening and rows:
        _STATS_CACHE["ts"] = time.time()
        _STATS_CACHE["n"] = n
        _STATS_CACHE["rows"] = rows
    return rows

# -*- coding: utf-8 -*-
r"""每日涨跌家数（沪深京全部 A 股口径）—— 抓取 / 入库 / 读取

口径与同花顺「涨跌分布」一致：
    统计范围 = 沪深京全部 A 股（含 ST / 创业板 / 科创板 / 北交所）
    上涨 = 当日涨跌幅 > 0，下跌 = 当日涨跌幅 < 0，平盘 = 涨跌幅 == 0，
    停牌（无行情）不计入三者，单独记 suspended。

数据源：东方财富行情列表接口（clist），一次分页拉全市场（约 60 页 / 7 秒）。
所有函数内部捕获异常，失败返回 None / 0，不影响主流程。
"""
import time
from concurrent.futures import ThreadPoolExecutor

import requests

_HEADERS = {
    "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                   "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"),
    "Referer": "https://quote.eastmoney.com/",
}
_CLIST = "https://push2.eastmoney.com/api/qt/clist/get"
# 沪深主板 + 创业板 + 科创板 + 北交所
_FS = "m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048"
_PAGE_SIZE = 100


def fetch_page(pn, pz=_PAGE_SIZE, timeout=20, fields="f12,f13,f14,f3", fid="f12"):
    """取第 pn 页 -> {"total": n, "rows": [...]}（失败返回空）"""
    url = ("%s?pn=%d&pz=%d&po=1&np=1&fltt=2&invt=2&fid=%s&fs=%s&fields=%s"
           % (_CLIST, int(pn), int(pz), fid, _FS, fields))
    for _ in range(3):
        try:
            j = requests.get(url, headers=_HEADERS, timeout=timeout).json()
            d = j.get("data") or {}
            return {"total": d.get("total") or 0, "rows": d.get("diff") or []}
        except Exception:
            time.sleep(0.4)
    return {"total": 0, "rows": []}


def fetch_all(workers=10):
    """拉全市场股票列表 -> [{"code","market","name","change_pct"}, ...]"""
    first = fetch_page(1)
    if not first["total"]:
        return []
    pages = (first["total"] + _PAGE_SIZE - 1) // _PAGE_SIZE
    out = list(first["rows"])
    if pages > 1:
        with ThreadPoolExecutor(max_workers=workers) as ex:
            for res in ex.map(lambda p: fetch_page(p), range(2, pages + 1)):
                out.extend(res["rows"])
    seen, uniq = set(), []
    for it in out:
        c = it.get("f12")
        if not c or c in seen:
            continue
        seen.add(c)
        uniq.append(it)
    return uniq


def count_breadth(rows):
    """统计涨跌家数 -> (up, down, flat, suspended)"""
    up = down = flat = suspended = 0
    for it in rows:
        v = it.get("f3")
        if v in ("-", None, ""):
            suspended += 1
            continue
        try:
            f = float(v)
        except Exception:
            suspended += 1
            continue
        if f > 0:
            up += 1
        elif f < 0:
            down += 1
        else:
            flat += 1
    return up, down, flat, suspended


def fetch_realtime(trade_date=None):
    """实时涨跌家数 -> {date, up, down, flat, total, suspended}，失败返回 None"""
    rows = fetch_all()
    if not rows:
        return None
    up, down, flat, susp = count_breadth(rows)
    if up + down + flat <= 0:
        return None
    return {"date": trade_date, "up": up, "down": down, "flat": flat,
            "total": len(rows), "suspended": susp}


def sync_today(trade_date, source="em_clist"):
    """抓今天的涨跌家数并入库（trade_date 由调用方给，接口本身不带日期）

    顺带把全市场「代码 -> 名称」存起来，用于识别 ST（评分口径要求非 ST）。
    """
    rows = fetch_all()
    if not rows:
        return None
    up, down, flat, susp = count_breadth(rows)
    if up + down + flat <= 0:
        return None
    row = {"date": trade_date, "up": up, "down": down, "flat": flat,
           "total": len(rows), "suspended": susp}
    try:
        import market_db as _mdb
        _mdb.save_market_breadth(row, source=source)
        _mdb.save_stock_names([{"code": it.get("f12"), "name": it.get("f14")}
                               for it in rows])
    except Exception:
        return row
    return row


def em_to_sina_symbol(code, market=None):
    """东方财富代码 -> 新浪行情符号（sh/sz/bj 前缀）"""
    code = str(code or "").strip()
    if not code:
        return ""
    if code.startswith(("92", "43", "83", "87", "88")):
        return "bj" + code              # 北交所（92xxxx 等）优先
    if market == 1 or code.startswith(("6", "9")):
        return "sh" + code
    if code.startswith(("4", "8")):
        return "bj" + code
    return "sz" + code


def a_share_symbols():
    """全市场 A 股代码 -> [("sh600000", "600000", "浦发银行"), ...]"""
    out = []
    for it in fetch_all():
        code = it.get("f12")
        sym = em_to_sina_symbol(code, it.get("f13"))
        if sym:
            out.append((sym, code, it.get("f14")))
    return out

# -*- coding: utf-8 -*-
"""两市成交额（沪市 + 深市）—— 抓取 / 入库 / 读取

口径：两市成交额 = 沪市成交额 + 深市成交额（与财经媒体口径一致，例：1.68 万亿）
      沪市取「上证综指 000001.SH」成交额，深市取「深证综指 399106.SZ」成交额，
      两者分别覆盖沪市、深市全部挂牌股票（含主板 / 创业板 / 科创板）。
存储单位：亿元（写入 market_turnover 表）。

数据来源（公开接口，免登录、免 Key）：
  · 历史：东方财富 push2his 指数日K（secid 1.000001 / 0.399106）→ f57 成交额(元)
  · 实时：新浪行情（sh000001 / sz399106）→ 成交额(元)，用于收盘后第一时间入库

所有函数内部捕获异常，失败返回 None / 0，绝不影响主流程。
"""
import json

import requests

_HEADERS = {
    "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                   "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"),
    "Referer": "https://quote.eastmoney.com/",
}
_SINA_HEADERS = {
    "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                   "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"),
    "Referer": "https://finance.sina.com.cn/",
}

_EM_KLINE = "https://push2his.eastmoney.com/api/qt/stock/kline/get"
SECID_SH = "1.000001"      # 上证综指
SECID_SZ = "0.399106"      # 深证综指


def _em_index_amount(secid, lmt=120, timeout=15):
    """东方财富指数日K -> {date: 成交额(亿元)}"""
    url = ("%s?secid=%s&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57"
           "&klt=101&fqt=0&end=20500101&lmt=%d" % (_EM_KLINE, secid, int(lmt)))
    try:
        j = requests.get(url, headers=_HEADERS, timeout=timeout).json()
    except Exception:
        return {}
    out = {}
    for row in ((j.get("data") or {}).get("klines") or []):
        p = str(row).split(",")
        if len(p) < 7:
            continue
        try:
            out[p[0]] = float(p[6]) / 1e8
        except Exception:
            pass
    return out


def fetch_history(days=120):
    """历史每日两市成交额（含今天，只要上游已更新）

    返回 [{date, sh, sz, amount}, ...]（按日期升序，单位：亿元）
    """
    sh = _em_index_amount(SECID_SH, days)
    sz = _em_index_amount(SECID_SZ, days)
    rows = []
    for d in sorted(set(sh) | set(sz)):
        a, b = sh.get(d), sz.get(d)
        if a is None and b is None:
            continue
        rows.append({"date": d,
                     "sh": round(a, 2) if a is not None else None,
                     "sz": round(b, 2) if b is not None else None,
                     "amount": round((a or 0.0) + (b or 0.0), 2)})
    return rows


def fetch_realtime():
    """实时两市成交额（新浪行情）-> {date, sh, sz, amount}，失败返回 None

    注意：盘中抓到的值是「截至此刻」的累计成交额（收盘后才是全天值）。
    """
    url = "https://hq.sinajs.cn/list=sh000001,sz399106"
    try:
        r = requests.get(url, headers=_SINA_HEADERS, timeout=10)
        r.encoding = "gbk"
        txt = r.text
    except Exception:
        return None
    got, date = {}, None
    for line in txt.splitlines():
        if "=" not in line:
            continue
        key, _, payload = line.partition("=")
        parts = payload.strip().strip(";").strip('"').split(",")
        if len(parts) < 11:
            continue
        try:
            amt = float(parts[9])          # 成交额（元）
        except Exception:
            continue
        for p in parts:
            p = p.strip()
            if len(p) == 10 and p[4] == "-" and p[7] == "-":
                date = p
                break
        if "sh000001" in key:
            got["sh"] = amt / 1e8
        elif "sz399106" in key:
            got["sz"] = amt / 1e8
    if not date or "sh" not in got or "sz" not in got:
        return None
    return {"date": date, "sh": round(got["sh"], 2), "sz": round(got["sz"], 2),
            "amount": round(got["sh"] + got["sz"], 2)}


def save_rows(rows, source="em_index"):
    """把成交额写入本地库（亿元），返回写入条数"""
    if not rows:
        return 0
    try:
        import market_db as _mdb
        return int(_mdb.save_turnover_batch(rows, source=source) or 0)
    except Exception:
        return 0


def sync_history(days=120, source="em_index"):
    """抓历史并入库（覆盖同日期旧值），返回写入条数"""
    return save_rows(fetch_history(days), source=source)


def sync_today(source="sina_rt"):
    """抓实时并入库（只写当天一条），返回该条 dict 或 None"""
    row = fetch_realtime()
    if not row:
        return None
    save_rows([row], source=source)
    return row


def sync_recent(days=10):
    """定时任务用：先补实时（当天），再用日K覆盖最近 days 天（更权威）。

    返回给调度器展示的字符串。
    """
    rt = sync_today()
    n = sync_history(days)
    return "实时=%s 历史=%d天" % (("%s 1.68万亿" % rt["date"]) if rt else "无", n)
