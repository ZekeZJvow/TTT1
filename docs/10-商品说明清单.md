## 三、功能清单（四大模块）

### 模块 1 · 📊 人气榜查询
- [x] 一键查询当日**人气 Top30**（同花顺）
- [x] 主数据源失败时**自动降级**东方财富热股榜，并在页面标注「已降级」
- [x] 榜单字段：排名 / 名称 / 代码 / **涨跌幅** / **连板数** / **连续上榜** / 所属梯队 / 概念标签 / 异动解读
- [x] 连板数语义化：`N天M板` → 「M连板（N天M板）」；`首板涨停` → 「首板（当日）」；无 → 「无」
- [x] 梯队划分：1–10 第一梯队 / 11–20 第二梯队 / 21–30 第三梯队
- [x] **连续上榜**：按本地库逐交易日回推，连续进前 30 才计数，>1 天高亮
- [x] 筛选：名称/代码搜索、概念筛选、仅看涨停、仅看 Top10
- [x] **历史回看**：日期范围选择 + 近 7 / 30 / 90 天快捷 + 「看最新」
- [x] 概览条：人气主线、涨停占比、数据来源、采集时间
- [x] 点击个股名 → 打开个股详情

### 模块 2 · 🎯 动态选股（参数化扫描）
- [x] 输入任意交易日，**自动推导前一交易日**，全市场日 K 扫描
- [x] 选股条件：**昨日未涨停 + 今日盘中冲高 > 9%**（沪深主板非 ST）
- [x] 漏斗图：入选池 / 冲高未封 / 被条件①剔除
- [x] 明细表（可排序）：代码 / 名称 / 涨跌幅 / 最高价 / 收盘价 / 最高涨幅 / 首次封板时间 / 连板 / 所属行业 / 状态
- [x] **导出 HTML 报告**
- [x] 与涨停池做**语义交叉校验**
- [x] 单题材**深度分析**（技术面 / 资金面 / 大单 / 量比等）

### 模块 3 · 🔥 当前题材热度
- [x] 自动采集三类当日事件：同花顺**热门话题**（带热度值）+ 人气榜**异动解读** + 个股**异动原因**
- [x] 事件文本匹配指数目录**自动归类题材**
- [x] 关键词词典 + 涨跌方向 → 判定**利好 / 利空**
- [x] 热度公式：`话题热度(万) + Σ(31 − 人气榜排名)`，只保留利好题材
- [x] 每题材取人气前 20 成分股，去重后按人气输出 **Top 50**
- [x] **每个题材给出利好原因/事件解读**
- [x] **日期切换**：列出库中已有数据的交易日，点一下即回看（如 2026-10-08 ⇄ 2026-09-30）
- [x] 点题材标签 → 从 Top50 中筛出该题材个股

### 模块 4 · 🗄️ 数据管理
- [x] 数据仓库概览、**按日期查看该日数据**、数据覆盖情况
- [x] 清理：清理分时 / 按日期清理 / 清空全部
- [x] **数据完整性校验**（一键校验，缺条提示）
- [x] 一键**导出 CSV / Excel**
- [x] 人气榜**历史回补**：检查缺失 → 开始回补（约可补最近 120 自然日）

- [x] 通知测试（邮件 / 企业微信 / 钉钉 / 微信 / Webhook）

### 附加 · 个股详情弹窗
- [x] **分时线**：价格 + 成交金额，鼠标移动实时显示涨跌幅

## 五、数据口径与规则

| 规则 | 说明 |
|------|------|
| 交易日判定 | 非交易日（周末/节假日）自动回溯到**最近已完成交易日** |
| 存储方式 | 按 `trade_date` 分行存储，**历史数据相互独立、不覆盖** |
| 涨跌幅 | `(当日收盘 − 前一日收盘) / 前一日收盘`；一字板用前收盘计算 |
| 异动解读取值优先级 | analyse_title ＞ analyse（≤25字）＞ topic.title ＞ 「无」 |
| 降级数据 | 降级源缺少的字段（如连板数）统一显示「无」并标注 |
