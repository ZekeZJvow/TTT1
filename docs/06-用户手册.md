# 用户手册

## 1. 快速上手

### 1.1 启动系统

**方式一：命令行启动**
`ash
cd stock-popularity
python server.py
`

**方式二：双击启动**
`
双击 start.bat 文件
`

启动成功后，命令行会显示：
`
==================================================
A股人气榜查询服务已启动
访问地址: http://localhost:5000
==================================================
`

### 1.2 打开页面

在浏览器地址栏输入：
`
http://localhost:5000
`

按回车键打开页面。

## 2. 功能说明

### 2.1 查询人气榜

**操作步骤**：
1. 点击页面中央的「查询人气榜」蓝色按钮
2. 等待数据加载（通常1-3秒）
3. 表格显示Top30股票数据

**数据说明**：
- 页面顶部显示「数据所属交易日」
- 如果是盘中查询，会提示「今日盘中，以下为上一交易日收盘数据」

### 2.2 查看股票详情

**操作步骤**：
1. 在表格中点击任意股票名称（蓝色文字）
2. 弹出详情窗口，包含：
   - 分时线图表
   - 日K线图表
   - 近期公告

**图表操作**：
- **查看具体数据**：鼠标悬停在图表上
- **切换图表**：点击「分时线」或「日K线」标签
- **缩放K线图**：拖动底部滑块
- **关闭窗口**：点击右上角×或按ESC键

### 2.3 筛选数据

**搜索功能**：
- 在搜索框输入股票名称或代码
- 表格实时过滤显示匹配结果

**概念筛选**：
- 点击下拉菜单选择特定概念
- 如「民营医院」「光纤概念」等

**涨停筛选**：
- 勾选「仅看涨停股」
- 只显示有连板标记的股票

**Top10筛选**：
- 勾选「仅看Top10」
- 只显示排名前10的股票

## 3. 数据说明

### 3.1 表格列说明

| 列名 | 说明 |
|------|------|
| 排名 | 人气排名，1-30 |
| 名称 | 股票名称，可点击查看详情 |
| 代码 | 股票代码 |
| 涨跌幅 | 当日涨跌百分比，红色上涨绿色下跌 |
| 连板数 | 连续涨停天数，无涨停显示"无" |
| 所属梯队 | Top10/Top20/Top30 |
| 概念标签 | 股票相关概念 |
| 异动解读 | 今日上涨原因简述 |

### 3.2 涨跌幅说明

- **计算公式**：(当日收盘价 - 前一日收盘价) / 前一日收盘价 × 100%
- **颜色**：红色表示上涨，绿色表示下跌
- **一字板**：开盘价=收盘价时，仍会显示正确涨幅

### 3.3 连板数说明

| 显示格式 | 含义 |
|----------|------|
| 2连板（2天2板） | 2天内连续涨停2次 |
| 3连板（4天3板） | 4天内连续涨停3次 |
| 首板（当日） | 当天首次涨停 |
| 无 | 非涨停股 |

## 4. 常见问题

### Q1: 点击查询没有反应
**可能原因**：
- 后端服务未启动
- 网络连接问题

**解决方案**：
1. 确认命令行窗口显示"服务已启动"
2. 尝试刷新页面（F5）

### Q2: 数据显示"已降级至东方财富热股榜"
**说明**：这是正常现象，当同花顺接口不可用时，系统自动切换到东方财富数据源。

### Q3: 行业显示"未获取"
**说明**：当前版本使用「概念标签」替代行业分类，这是正常显示。

### Q4: 图表显示"暂无数据"
**可能原因**：
- 股票代码不存在
- 数据源暂时不可用

**解决方案**：稍后重试或更换其他股票查看
