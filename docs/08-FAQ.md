# 常见问题（FAQ）

## 通用问题

### Q1: 这个软件是什么？
**A**: A股人气榜查询系统是一款股票数据分析工具，可以实时查询同花顺个股人气榜Top30数据，并提供K线图表和公告信息。

### Q2: 软件是免费的吗？
**A**: 本软件为私有软件，使用条款请咨询开发者。

### Q3: 需要联网吗？
**A**: 是的，软件需要联网才能获取实时股票数据。

### Q4: 支持哪些浏览器？
**A**: 支持所有现代浏览器：
- Google Chrome 90+
- Microsoft Edge 90+
- Firefox 88+
- Safari 14+

## 安装部署

### Q5: 如何安装？
**A**: 
1. 确保已安装Python 3.8+
2. 解压项目文件
3. 运行 pip install -r requirements.txt
4. 运行 python server.py

详见 [部署指南](05-部署指南.md)。

### Q6: 启动报错怎么办？
**A**: 常见错误及解决方案：

| 错误信息 | 解决方案 |
|----------|----------|
| 端口被占用 | 修改server.py中的端口号 |
| 依赖缺失 | 运行pip install安装依赖 |
| Python版本过低 | 升级到Python 3.8+ |

### Q7: 如何开机自启？
**A**: 
- Windows：将启动脚本放入启动文件夹
- Linux：创建systemd服务

详见 [部署指南](05-部署指南.md)。

## 功能使用

### Q8: 为什么显示"已降级至东方财富热股榜"？
**A**: 当同花顺接口不可用时（网络问题、接口维护等），系统会自动切换到东方财富数据源。这是正常的降级机制，不影响使用。

### Q9: 涨跌幅是如何计算的？
**A**: 涨跌幅 = (当日收盘价 - 前一日收盘价) / 前一日收盘价 × 100%
- 一字板（开盘=收盘）也会显示正确涨幅
- 使用前一日收盘价作为基准，而非当日开盘价

### Q10: 连板数是怎么判断的？
**A**: 根据同花顺返回的popularity_tag字段解析：
- "2天2板" → 显示"2连板（2天2板）"
- "首板涨停" → 显示"首板（当日）"
- 无标记 → 显示"无"

### Q11: 数据多久更新一次？
**A**: 
- 接口数据实时获取
- 本地缓存10分钟
- 点击查询按钮时获取最新数据

### Q12: 为什么某些股票没有概念标签？
**A**: 概念标签来自同花顺接口，部分股票可能未被收录。这是数据源的限制。

## 技术问题

### Q13: 如何修改端口号？
**A**: 编辑 server.py，修改最后一行：
`python
app.run(host='0.0.0.0', port=5000, debug=True)
`
将 5000 改为你想要的端口号。

### Q14: 如何关闭调试模式？
**A**: 将 debug=True 改为 debug=False：
`python
app.run(host='0.0.0.0', port=5000, debug=False)
`

### Q15: 如何查看日志？
**A**: 服务运行时，命令行会显示访问日志：
`
127.0.0.1 - - [23/Sep/2026 23:22:52] "GET /api/hotlist HTTP/1.1" 200 -
`

### Q16: 数据安全吗？
**A**: 
- 软件仅读取公开的股票数据
- 不存储用户个人信息
- 不记录用户操作行为
- 所有数据仅在本地处理
