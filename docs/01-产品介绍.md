## 2. 产品定位

A股人气雷达是一款**单机部署、手动查询**的股票数据分析工具，帮助用户快速获取同花顺个股人气榜Top30数据，配合可视化图表辅助投资决策。

## 3. 核心价值

### 解决的问题
- 传统看盘软件信息分散，难以快速获取人气榜数据
- 需要手动切换多个平台查看不同维度数据
- 缺乏一站式的排行榜+K线图+公告整合视图

### 核心优势
| 优势 | 说明 |
|------|------|
| 数据实时 | 对接同花顺、东方财富等主流数据源 |
| 可视化 | 分时线、日K线图表直观展示 |
| 一站式 | 排行榜+K线图+公告，一个页面搞定 |
| 降级机制 | 主数据源不可用时自动切换备用源 |
| 轻量部署 | 无需数据库，本地一键启动 |

## 5. 技术亮点

### AI辅助开发模式
本项目采用AI辅助开发模式，具有以下特点：
- **快速迭代**：需求提出后可快速实现
- **文档同步**：代码与文档同步更新
- **知识沉淀**：所有决策过程可追溯

### 架构设计
- **前后端分离**：前端纯静态，后端代理转发
- **多数据源**：支持同花顺、东方财富双数据源
- **内存缓存**：10分钟缓存避免频繁请求
- **降级机制**：主源失败自动切换备用源
