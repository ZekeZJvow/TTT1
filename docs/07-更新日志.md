# 更新日志

所有重要更改都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---

## [1.0.0] - 2026-09-23

### 新增

#### 核心功能
- 人气榜Top30数据查询
- 手动点击触发查询（非定时推送）
- 交易日自动识别（周末回溯）
- 数据降级机制（同花顺→东方财富）

#### 数据展示
- 涨跌幅显示（基于前一日收盘价计算）
- 连板数识别（N天M板、首板涨停）
- 梯队划分（Top10/Top20/Top30）
- 概念标签展示
- 异动解读显示

#### 图表功能
- 分时线图表展示
- 日K线图表展示
- 涨跌幅tooltip显示
- 成交金额显示（单位：亿）
- 十字准线穿透显示

#### 筛选功能
- 按名称/代码搜索
- 按概念筛选
- 仅看涨停股
- 仅看Top10

#### 资讯功能
- 个股公告查询（东方财富公告接口）
- 近期资讯展示

#### 界面优化
- 涨停行高亮显示
- 非涨停股连板数显示"无"
- 底部数据来源标注
- 响应式设计

### 修复
- 一字板涨跌幅显示为0%的问题
- 同花顺数据解析失败的问题
- 日K线数据获取失败的问题

### 已知问题
- 交易日历仅排除周末，未接入法定节假日
- 概念标签非严格行业分类
- 部分股票名称需要手动维护
