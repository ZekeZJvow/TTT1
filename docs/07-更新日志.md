## [1.1.0] - 2026-10-01

### 新增：动态选股（参数化扫描）
- **输入任意交易日**，自动推导前一交易日（用上证指数日K当交易日历，天然覆盖节假日）
- **全市场扫描**：沪深主板 非ST 全量 ~3050 只，并发抓取日K，约 30 秒
- **参数化条件引擎**（`screener.py`）：
  - 条件① 前一交易日(D-1) 首次涨停时间取反 → D-1 全天未触及涨停价
  - 条件② (D最高价 − D-1收盘价) ÷ D-1收盘价 > 0.09（阈值可配置）
  - 条件③ 沪深主板 且 非ST
- **语义交叉校验**：价格法（最高价 ≥ 涨停价）与东方财富涨停池/炸板池交叉比对，输出冲突数
- **涨停信息补全**：首次封板时间、连板数、所属行业（来自东方财富涨停/炸板池）
- **选股漏斗可视化**：全市场 → 条件② → +条件① → 封板/未封 / 被剔除
- **三张明细表**：入选池 / 冲高未封 / 被条件①剔除，可切换
- **一键导出 HTML 报告**：7 章节（条件、漏斗、校验、三张明细表、来源声明）
- **异步任务 + 进度条**：`/api/screen/start` + `/api/screen/status`，按日期缓存
- **表格排序**：12 列表头全部可点击，升序/降序切换，空值恒排最后，未排序列显示 ⇅ 提示
- **默认日期智能填充**：打开页面自动取「最近交易日」（跳过周末与法定节假日），不再落到休市日
- **新增接口** `/api/trading-days?n=`：返回最近 N 个交易日
- **行业补全**：涨停/炸板池之外的行（盘中冲高但未触板）改用「新浪行业」48 板块全量映射补齐，行业空缺从 26 行降到 13 行；仍无数据的统一显示「无」
- **空值展示统一**：所属行业 / 首次封板 / 连板 无数据时一律显示「无」（原显示「—」）

### 新增：数据源
- 新浪财经日K（全市场扫描主通道，稳定高速）
- 东方财富涨停池 / 炸板池（历史日期查询 + 语义校验）

### 变更
- 页面新增顶部模式切换：「📊 人气榜查询」/「🎯 动态选股」
- 新增 `screener.py` 选股引擎模块

### 已知限制
- 成交额为估算值（成交量 × 均价），非交易所口径
- 未做除权除息校正（送转/分红日可能出现价格跳变）
- 交易日历依赖上证指数日K，历史过深（> 1.5 年）时数据长度受限
- 仅覆盖沪深主板，不含创业板/科创板（20cm）与北交所

## [1.1.8] - 2026-10-05

### 新增：点击题材标签 → 筛选 Top50 个股表
原来点击题材标签触发的是「题材深度分析」（耗时 10–40 秒）。现在改为**即时前端筛选**，零等待：

- 点击「房地产」→ Top50 表只显示该题材的股票（实测 50 行 → **10 行**）
- 标签高亮显示选中态；再次点击同一标签可取消
- 表格上方显示筛选栏：`已筛选：房地产　显示 10 只（Top50 中属于该题材的股票）`
- 筛选栏提供两个按钮：
  - 「✕ 显示全部」→ 还原全部 50 行
  - 「🔎 该题材深度分析」→ 触发原来的深度分析（需要时才跑）

**技术**：每只股票已带 `themes` 字段，纯前端过滤，**不需要后端请求**，所以是瞬时的。

### 实测
```
点击「房地产」→ 50 行 → 10 行（全部为房地产相关）
点击「显示全部」→ 还原 50 行，筛选栏隐藏，标签取消高亮
```

## [1.1.7] - 2026-10-04

### 新增：各题材「利好原因解读」
原来题材标签只显示「利好 +N」，看不出**为什么利好**。现在每个题材下方展开：

| 板块 | 内容 |
|------|------|
| **事件** | 命中的热门话题标题 + 热度值 + 话题描述（即触发利好的大事件原文） |
| **个股** | 命中的人气股 + 人气榜排名 + 该股的异动解读 |
| **依据** | 命中的利好关键词（如「突破/量产/增长」）；无命中词时明确标注「由涨停/涨跌方向判定」 |

### 实测样例
```
【房地产】利好 +2  热度 98.4
  事件：财政部：购房贷款贴息政策落地（49.4万）
        财政部推出居民购房贷款贴息政策，年化贴息1%、期限最长5年…
  事件：稳定房地产市场！上海推新政策（30.9万）
  个股：深物业A（人气榜第13名）房地产开发+物业管理+深圳国资
  依据：无命中利好词，由涨停/涨跌方向判定

【创新药】利好 +16  热度 88.3
  事件：创新药出海加速价值重估！（42.3万）
  个股：哈药股份（第8）、美诺华（第21）、南华生物（第24）
  依据：命中利好词：合作、增长、扭亏
```

### 修复
- 精简利好词典：移除「入选/首批/试点/牌照/资质」等过于泛化、易误判的词
  （此前房地产被误判命中「首批/资质」）

### 新增 API 字段
`rows[].topics[].desc`（话题描述）、`rows[].stockReasons`（个股解读）、`rows[].bullWords`（命中利好词）

## [1.1.4] - 2026-10-04

### 变更：热门题材发现逻辑 改为「事件驱动 + 人气排序」
原逻辑按板块指数价格动量排序，与"热点题材"语义不符（热度≠涨幅）。现改为：

```
① 当日事件采集   人气榜 Top30 的异动解读(analyse_title/analyse)
                 + 个股异动原因(anomaly-stock，最多50只)
       ↓
② 题材归类       事件文本 → 匹配 710 个概念/行业指数目录
       ↓
③ 利好/利空判定   利好词典(收购/中标/获批/业绩增长…) + 利空词典(减持/立案/亏损…)
                 + 涨跌方向确认(涨停记 +3，跌停记 -3)
                 net = 词典净分 + 方向分；net>0 判为利好
       ↓
④ 取成分股       利好题材 → index constituents
       ↓
⑤ 人气排序       人气榜排名优先 → 热度趋势补全 → 未上榜置底
```

### 新增
- `event_theme_service.py`：事件驱动题材引擎
- `GET /api/event-themes?limit=6&stocks=10`：返回利好题材及其按人气排序的成分股
- 页面「自动发现」区块改为展示**事件驱动利好题材**（含净分、人气股数、热度）
- 无事件数据时（非交易日/未开盘）自动回退到原板块动量榜并标注

### 修复
- 成分股剔除 ST / *ST / 退市股
- 题材匹配改为三级优先（概念标签精确 > 解读标题 > 长文本，长文本仅匹配 3 字以上题材名），
  修复 "参股银行" 误命中 "银行" 题材的问题（题材数 72 → 60）
- 人气趋势查询配额在各题材间平均分配，避免靠后题材全部"未上榜"

### 实测（2026-10-04）
- 事件源：人气榜 30 只 + 异动 0 只（假期）→ 识别题材 60 个（利好 44 / 利空 6）
- 入选利好题材：机器人 / 物业管理 / 创新药 / 注册制次新股 / 租售同权 / 钠离子电池
- 点击「机器人」→ 1294 只候选 → 输出 20 行，按人气排名（九阳股份第1、万科A第6）

### 已知限制
- **无 A股新闻接口**：事件源只能用「人气榜异动解读 + 个股异动原因」，且异动数据仅当日
- 利好/利空为**关键词规则判定**，非语义模型，新说法可能漏判（词典可维护）
- 事件源仅覆盖人气榜Top30 + 异动榜，冷门股事件抓不到

## [1.1.3] - 2026-10-04

### 新增：自动发现近期热门题材
- **背景**：原来每次都要手动输入题材名称，用户需要自己知道当前市场在炒什么。
- **实现**：新增 `discover_hot_themes()`（`theme_heat_service.py`）
  1. 拉取全量 **概念指数(390) + 行业指数(320) = 710 个**目录
  2. 分批 `index snapshot`（400个/次，约 1 秒）取最新涨幅与成交额
  3. 剔除成交额 < 1 亿的冷门指数
  4. 按当日涨幅取前 24，补拉近 5 日指数日线（并发）
  5. 综合排序：`score = 当日涨幅 + 近5日涨幅 × 0.6`
- **接口**：`GET /api/theme-hot?limit=12&lookback=5`（结果缓存 15 分钟，二次调用 0.3 秒）
- **前端**：进入「当前题材热度」标签页时自动扫描，渲染 12 个可点击题材标签
  （显示题材名、当日涨幅、近5日涨幅），点击即自动查询；另有「↻ 重新扫描」按钮
- **已知取舍**：初筛只看当日强势品种，因此「近5日强、当日弱」的题材可能不入榜（页面已注明）
- **全自动分析（无需任何手动输入）**：首次进入该标签页时，程序自动完成
  「扫描 710 个指数 → 列出热门题材 → 自动填入最热题材 → 自动执行分析」，
  页面显示「⚡ 已自动分析当前最热题材「XXX」」提示；手动输入框保留，可随时改查其他题材

### 实测
- 全量扫描 710 个指数耗时约 12 秒
- 2026-10-04 识别出**医药生物产业链**集群：疫苗 +4.82%、生物制品 +4.63%、医疗美容 +2.85%、
  重组蛋白 +3.78%、医疗研发外包 +4.30%、血液制品 +3.00% 等
- 点击「疫苗」标签 → 10 秒返回 20 行结果

## [3.1.0] - 2026-10-08

### 变更：品牌更名为「A股人气雷达」
- 产品名由「A股人气榜查询系统」正式更名为 **A股人气雷达**
- 副标题统一为「人气榜 · 题材热度 · 首板选股 · 数据复盘」
- 页面标题 / 页面大标题 / 浏览器标签页 / exe 文件名 / 桌面快捷方式 / 计划任务 全部同步更名
- exe 更名为 `A股人气雷达.exe`；计划任务更名为 `A股人气雷达-自动启动`、`A股人气雷达-每日8点启动`
- 模块名保持不变：「人气榜查询」仍是第 1 个功能模块的名称

### 修复：题材存档被覆盖（数据安全，重要）
- 问题：题材页请求带 `stocks=20`，绕过了后端「读库优先」判断，会重新实时抓取并归到「上一交易日」落库，
  把该交易日的收盘存档覆盖掉（不可恢复）；周末/节假日一打开页面就会触发
- 修复：`/api/event-themes` 改为**非交易时段只读不写**，且读库优先不再受参数影响
- 新增自动化测试：`tests/test_theme_no_overwrite.py`（4 项）、`tests/test_theme_history_e2e.py`（17 项）

### 修复：源码模式与打包模式用了两个数据库
- 问题：`serve.py`（源码模式）默认用 `data\market.db`，exe（打包模式）用 `dist\data\market.db`，
  导致历史数据「时有时无」
- 修复：`serve.py` 统一指向 `dist\data\market.db`

### 变更：动态选股明细表列调整
- 删除：D-1收盘、成交额(估)
- 改名：D最高→最高价、D收盘→收盘价、收盘涨跌→涨跌幅、首次封板→首次封板时间
- 调序：最高涨幅 移到 收盘价 之后

### 新增：题材热度支持按日回看
- 题材页列出库中已有数据的交易日，点一下即回看；查看历史日时明确标注「回看交易日 X」
