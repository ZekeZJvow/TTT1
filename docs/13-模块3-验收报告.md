### 6.2 ④ —— 规格内部口径冲突（10-08 已定位，**不改代码**）

`_build_uncached` 按规格【七.4】实现：`net += lex.net + 方向分`，而 `bull += lex.bull + (方向分>0?1:0)`、`bear += lex.bear + (方向分<0?1:0)`。
方向分取值 ±1/±2/±3，所以 `net` 加的是原值、`bull−bear` 加的是 ±1 —— 两者天然不等（如「机器人」差 +6、「人工智能」差 −8）。
要让 ④ 变绿，只能改打分口径（例如 `net` 也只加 ±1），但那会直接违背规格【七.4】的明文。因此**维持规格实现，④ 记为已知冲突**。

### 6.3 ⑰ —— Top50 多了一列「涨跌幅」

定位：`app.js:1287-1302` 每行渲染 8 个 `<td>`（排名 / 代码 / 名称 / 涨跌幅 / 所属题材 / 人气 / 连续上榜 / 题材热度），`index.html:283-292` 表头同步 8 列。
`git log -S kline_change_map` → `9bf9d8f`（2026-10-09）「v3.2: 题材Top50 增加涨跌幅列并把代码移到名称前」。同样晚于本规格。
行数断言部分是准的（`tr=50 == len(topStocks)=50`），只有「7 格」不符。
