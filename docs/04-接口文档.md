## 接口列表

### 1. 获取人气榜数据

**接口地址**：/api/hotlist

**请求方式**：GET

**请求参数**：无

**返回示例**：
`json
{
    "success": true,
    "trading_day": "2026-09-22",
    "message": "今日未开盘，以下为上一交易日收盘数据",
    "source": "同花顺人气榜",
    "degraded": false,
    "collection_time": "2026-09-22 23:22:52",
    "data": [
        {
            "rank": 1,
            "name": "哈药股份",
            "code": "600664",
            "rise_and_fall": 10.0606,
            "consecutive_boards": "2连板（2天2板）",
            "tier": "第一梯队·人气Top10",
            "concept_tag": "民营医院, 维生素",
            "anomaly_analysis": "创新药+医药工业+业绩增长",
            "is_hot": true
        }
    ],
    "summary": {
        "main_direction": "人气主线集中在民营医院方向",
        "hot_proportion": "涨停股与非涨停股参半"
    }
}
`

**返回字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 |
| trading_day | string | 数据所属交易日 |
| message | string | 交易日提示信息 |
| source | string | 数据来源 |
| degraded | boolean | 是否降级到备用源 |
| collection_time | string | 数据采集时间 |
| data | array | 股票数据列表 |
| data[].rank | number | 人气排名 |
| data[].name | string | 股票名称 |
| data[].code | string | 股票代码 |
| data[].rise_and_fall | number | 涨跌幅（百分比） |
| data[].consecutive_boards | string | 连板数（如"2连板（2天2板）"或"无"） |
| data[].tier | string | 所属梯队 |
| data[].concept_tag | string | 概念标签 |
| data[].anomaly_analysis | string | 异动解读 |
| data[].is_hot | boolean | 是否涨停 |
| summary | object | 统计摘要 |
| summary.main_direction | string | 人气主线方向 |
| summary.hot_proportion | string | 涨停占比描述 |

### 2. 获取分时数据

**接口地址**：/api/stock/{code}?type=minute

**请求方式**：GET

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 股票代码，如600664 |

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 固定值"minute" |

**返回示例**：
`json
{
    "success": true,
    "prev_close": 8.25,
    "data": [
        {
            "time": "09:30",
            "price": 9.02,
            "volume": 312144,
            "amount": 281553888.00
        }
    ]
}
`

**返回字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 |
| prev_close | number | 前一日收盘价 |
| data | array | 分时数据列表 |
| data[].time | string | 时间（HH:MM） |
| data[].price | number | 当前价格 |
| data[].volume | number | 成交量（手） |
| data[].amount | number | 成交金额（元） |

### 5. 动态选股 - 启动扫描（异步）

**接口地址**：`/api/screen/start`

**请求方式**：GET

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 目标交易日，格式 YYYY-MM-DD |

**返回示例**：
```json
{ "success": true, "jobId": "c41f8d1b6e4d", "cached": false }
```

- `cached=true` 时直接返回 `result`，无需轮询
- 命中缓存时 `result` 字段包含完整扫描结果

### 6. 动态选股 - 查询进度

**接口地址**：`/api/screen/status`

**请求方式**：GET

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| jobId | string | 是 | 启动接口返回的任务号 |

**返回示例**：
```json

  "success": true,
  "state": "running",
  "done": 1500,
  "total": 3052,
  "message": "已扫描 1500/3052"
}
```

`state` 取值：`running` / `done` / `error`；完成后附带 `result` 字段。

### 7. 动态选股 - 同步扫描

**接口地址**：`/api/screen`

**请求方式**：GET

**请求参数**：`date`（YYYY-MM-DD）

**说明**：阻塞式扫描（约 30 秒），结果自动写入缓存。适合脚本调用。

**返回结果结构**：
```json
{
  "success": true,
  "target": "2026-09-30",
  "prevDay": "2026-09-29",
  "universe": 3052,
  "scanned": 3042,
  "suspended": 10,
  "funnel": {
    "cond2": 72, "final": 57, "sealed": 37, "broken": 20, "removedByCond1": 15
  },
  "sealedRate": 64.9,
  "rows": [ { "code": "600383", "name": "金地集团", "closePrev": 2.55, "high": 2.81,
              "gainHigh": 10.2, "close": 2.74, "gainClose": 7.45,
              "amountEst": 1269000000, "sealed": false, "broke": true,
              "firstSeal": "", "boards": null, "sector": "", "poolState": "" } ],
  "brokenRows": [],
  "removedRows": [],
  "validation": {
    "poolZtCount": 52, "poolZbCount": 12, "prevPoolCount": 65,
    "mismatch": [], "errors": []
  },
  "elapsed": 35.1,
  "threshold": 0.09,
  "source": "新浪财经（日K） + 东方财富（涨停/炸板池校验）",
  "collectedAt": "2026-10-01 18:29:28"
}
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| target / prevDay | 数据所属交易日 / 前一交易日（自动推导） |
| universe / scanned / suspended | 主板非ST总数 / 实际扫描 / 停牌跳过 |
| funnel.cond2 | 仅满足条件②的数量 |
| funnel.final | 同时满足条件①②的数量（入选） |
| funnel.sealed / broken | 其中封住涨停 / 冲高未封 |
| funnel.removedByCond1 | 满足条件②但被条件①剔除 |
| sealedRate | 封板率（%） |
| rows / brokenRows / removedRows | 入选池 / 冲高未封 / 被剔除 明细 |
| validation.mismatch | 价格法与涨停池法冲突明细（应为空） |
| sectorFilled | 本次通过「新浪行业」映射补全的行数 |
| threshold | 条件②阈值（默认 0.09） |

**明细行字段**：

| 字段 | 说明 |
|------|------|
| code / name | 代码 / 名称 |
| closePrev | D-1 收盘价 |
| high / low / open / close | D 日 最高/最低/开盘/收盘 |
| gainHigh / gainClose | D 最高涨幅% / 收盘涨跌幅% |
| amountEst | 成交额估算（元） |
| sealed / broke | 是否收盘封板 / 是否触及涨停后未封 |
| firstSeal / lastSeal | 首次/最后封板时间（HH:MM:SS） |
| boards | 连板数 |
| sector | 所属行业（东财涨停池优先，缺失时用新浪行业补齐，仍无则「无」） |

### 8. 动态选股 - 导出 HTML 报告

**接口地址**：`/api/screen/report`

**请求方式**：GET

**请求参数**：`date`（YYYY-MM-DD，必须先完成该日期的扫描）

**返回**：`Content-Type: text/html; charset=utf-8`，可直接在浏览器打开或另存为 HTML 报告。

报告共 7 章：选股条件、选股漏斗、语义交叉校验、入选池明细、冲高未封样本、被条件①剔除、数据来源与声明。

未扫描时返回 `404` 与提示文本。

### 9. 交易日列表

**接口地址**：`/api/trading-days`

**请求方式**：GET

**请求参数**：`n`（可选，返回条数，默认 10，范围 1–60）

**返回示例**：
```json
{ "success": true, "days": ["2026-09-30", "2026-09-29", "2026-09-28", "2026-09-24"] }
```

用于页面默认日期填充（自动跳过周末与法定节假日）以及非交易日回溯提示。

### 10. 自动发现近期热门题材

**接口地址**：`/api/theme-hot`

**请求方式**：GET

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| limit | int | 否 | 返回题材数，默认 12（3–30） |
| lookback | int | 否 | 回看交易日数，默认 5（2–20） |

**返回示例**：
```json
{
  "success": true,
  "as_of": "2026-10-04",
  "lookback": 5,
  "scanned": 710,
  "liquid": 709,
  "rows": [
    { "name": "疫苗", "thscode": "884239.TI", "tag": "industry",
      "d1": 4.82, "d5": 3.27, "score": 6.78, "turnover": 5700000000 }
  ],
  "method": "全量概念+行业指数快照按最新涨幅初筛，再叠加近5日涨幅加权排序",
  "note": "初筛只看当日强势品种，因此「近5日强、当日弱」的题材可能不入榜。",
  "elapsed": 11.88
}
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| as_of | 数据日期 |
| scanned / liquid | 参与扫描的指数数 / 通过成交额门槛的指数数 |
| rows[].name / thscode | 题材名称 / 同花顺指数代码 |
| rows[].d1 / d5 | 当日涨幅% / 近 N 日涨幅% |
| rows[].score | 综合分 = d1 + d5 × 0.6 |
| rows[].turnover | 指数成交额（元） |

结果缓存 15 分钟。

### 11. 当日事件驱动题材 + 人气排序

**接口地址**：`/api/event-themes`

**请求方式**：GET

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| limit | int | 否 | 返回利好题材数，默认 6（1–20） |
| stocks | int | 否 | 每个题材返回的成分股数，默认 10（3–50） |

**返回示例**：
```json
{
  "success": true,
  "as_of": "2026-10-04 21:24",
  "eventCount": 30,
  "themeCount": 60,
  "bullCount": 44,
  "bearCount": 6,
  "sources": { "hotlist": 30, "anomaly": 0 },
  "rows": [
    {
      "name": "机器人", "thscode": "884218.TI", "tag": "cn_concept",
      "heatScore": 58, "netScore": 6, "verdict": "利好", "stockCount": 2,
      "stockTotal": 23,
      "stocks": [
        { "ticker": "688836", "name": "宇树科技-W", "hotRank": 15, "trendRank": null },
        { "ticker": "300276", "name": "三丰智能", "hotRank": null, "trendRank": 2033 }
      ]
    }
  ],
  "allThemes": [ { "name": "机器人", "verdict": "利好", "heatScore": 58, "netScore": 6 } ],
  "method": "当日人气榜异动解读 + 个股异动原因 → 匹配指数目录归类题材 → 关键词词典+涨跌方向判定利好利空 → 利好题材取成分股 → 按人气排名排序",
  "caveat": "事件源仅覆盖当日（人气榜Top30与异动榜），且利好利空为关键词规则判定，非语义模型，可能漏判新说法。",
  "elapsed": 44.5
}
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| eventCount | 参与分析的当日事件股数（人气榜 + 异动，去重） |
| themeCount / bullCount / bearCount | 识别到的题材数 / 利好 / 利空 |
| sources | 事件来源条数（hotlist 人气榜 / anomaly 异动 / topics 热门话题） |
| rows[].name / thscode | 利好题材名称 / 同花顺指数代码 |
| rows[].heatScore | 综合热度 = 话题热度(万) + Σ(31 − 人气榜排名) |
| rows[].topicHeat | 话题热度（万），来自同花顺热门话题 hot_value |
| rows[].popHeat | 人气权重 = Σ(31 − 人气榜排名) |
| rows[].topics | 命中的热门话题列表（title + hot） |
| topics | 当日热门话题原文（全部 15 条，含 title / desc / hot / url） |
| rows[].netScore | 利好净分 = 词典净分 + 涨跌方向分（>0 判为利好） |
| rows[].verdict | 利好 / 利空 / 中性 |
| rows[].stockCount / stockTotal | 命中该题材的事件股数 / 成分股总数 |
| rows[].stocks[] | 成分股，按人气排序（hotRank 人气榜排名 / trendRank 热度排名，均无则置底） |
| allThemes | 全部题材概览（按热度，取前 20） |
| caveat | 数据局限说明 |

结果缓存 5 分钟。非交易日/无事件数据时返回 `success:false`，前端自动回退到 `/api/theme-hot`。

## 错误响应

当请求失败时，返回以下格式：
`json
{
    "success": false,
    "error": "错误描述信息"
}
`

**常见错误码**：

| HTTP状态码 | 说明 |
|------------|------|
| 200 | 请求成功 |
| 500 | 服务器内部错误 |
