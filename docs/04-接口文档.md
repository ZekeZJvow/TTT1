# API接口文档

## 基础信息

| 项目 | 说明 |
|------|------|
| 基础地址 | http://localhost:5000 |
| 数据格式 | JSON |
| 请求方式 | GET |
| 编码 | UTF-8 |

---

## 接口列表

### 1. 获取人气榜数据

**接口地址**：/api/hotlist

**请求方式**：GET

**请求参数**：无

**返回示例**：
`json
{
    "success": true,
    "trading_day": "2026-09-22",
    "message": "今日未开盘，以下为上一交易日收盘数据",
    "source": "同花顺人气榜",
    "degraded": false,
    "collection_time": "2026-09-22 23:22:52",
    "data": [
        {
            "rank": 1,
            "name": "哈药股份",
            "code": "600664",
            "rise_and_fall": 10.0606,
            "consecutive_boards": "2连板（2天2板）",
            "tier": "第一梯队·人气Top10",
            "concept_tag": "民营医院, 维生素",
            "anomaly_analysis": "创新药+医药工业+业绩增长",
            "is_hot": true
        }
    ],
    "summary": {
        "main_direction": "人气主线集中在民营医院方向",
        "hot_proportion": "涨停股与非涨停股参半"
    }
}
`

**返回字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 |
| trading_day | string | 数据所属交易日 |
| message | string | 交易日提示信息 |
| source | string | 数据来源 |
| degraded | boolean | 是否降级到备用源 |
| collection_time | string | 数据采集时间 |
| data | array | 股票数据列表 |
| data[].rank | number | 人气排名 |
| data[].name | string | 股票名称 |
| data[].code | string | 股票代码 |
| data[].rise_and_fall | number | 涨跌幅（百分比） |
| data[].consecutive_boards | string | 连板数（如"2连板（2天2板）"或"无"） |
| data[].tier | string | 所属梯队 |
| data[].concept_tag | string | 概念标签 |
| data[].anomaly_analysis | string | 异动解读 |
| data[].is_hot | boolean | 是否涨停 |
| summary | object | 统计摘要 |
| summary.main_direction | string | 人气主线方向 |
| summary.hot_proportion | string | 涨停占比描述 |

### 2. 获取分时数据

**接口地址**：/api/stock/{code}?type=minute

**请求方式**：GET

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 股票代码，如600664 |

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 固定值"minute" |

**返回示例**：
`json
{
    "success": true,
    "prev_close": 8.25,
    "data": [
        {
            "time": "09:30",
            "price": 9.02,
            "volume": 312144,
            "amount": 281553888.00
        }
    ]
}
`

**返回字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 |
| prev_close | number | 前一日收盘价 |
| data | array | 分时数据列表 |
| data[].time | string | 时间（HH:MM） |
| data[].price | number | 当前价格 |
| data[].volume | number | 成交量（手） |
| data[].amount | number | 成交金额（元） |

### 3. 获取日K线数据

**接口地址**：/api/stock/{code}?type=daily

**请求方式**：GET

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 股票代码，如600664 |

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 固定值"daily" |

**返回示例**：
`json
{
    "success": true,
    "data": [
        {
            "date": "2026-09-22",
            "open": 9.02,
            "close": 9.08,
            "high": 9.08,
            "low": 8.68,
            "volume": 308205511
        }
    ]
}
`

**返回字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 |
| data | array | K线数据列表 |
| data[].date | string | 日期（YYYY-MM-DD） |
| data[].open | number | 开盘价 |
| data[].close | number | 收盘价 |
| data[].high | number | 最高价 |
| data[].low | number | 最低价 |
| data[].volume | number | 成交量（股） |

### 4. 获取个股公告

**接口地址**：/api/stock/{code}/news

**请求方式**：GET

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 股票代码，如000002 |

**返回示例**：
`json
{
    "success": true,
    "data": [
        {
            "title": "万科A:A股股票交易异常波动公告",
            "date": "2026-09-23",
            "source": "东方财富公告",
            "url": "https://data.eastmoney.com/notices/detail/000002/xxx.html"
        }
    ]
}
`

**返回字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 |
| data | array | 公告列表 |
| data[].title | string | 公告标题 |
| data[].date | string | 发布日期 |
| data[].source | string | 数据来源 |
| data[].url | string | 公告链接 |

---

## 错误响应

当请求失败时，返回以下格式：
`json
{
    "success": false,
    "error": "错误描述信息"
}
`

**常见错误码**：

| HTTP状态码 | 说明 |
|------------|------|
| 200 | 请求成功 |
| 500 | 服务器内部错误 |
