# 部署指南

## 1. 环境要求

### 硬件要求
- **最低配置**：1核CPU / 1GB内存 / 100MB磁盘空间
- **推荐配置**：2核CPU / 2GB内存 / 500MB磁盘空间

### 软件要求
| 软件 | 版本要求 | 说明 |
|------|----------|------|
| Python | 3.8+ | 运行环境 |
| pip | 最新版 | 包管理器 |
| 网络 | 需要访问外网 | 调用第三方API |

### 操作系统
- Windows 10/11
- Windows Server 2016+
- Linux (Ubuntu/CentOS)
- macOS

---

## 2. 安装部署

### 2.1 获取项目文件

将 stock-popularity 文件夹完整复制到目标位置。

**示例路径**：
`
C:\stock-popularity\
`

### 2.2 安装Python依赖

打开命令行，进入项目目录：

`ash
cd C:\stock-popularity
`

安装依赖：

`ash
pip install -r requirements.txt
`

**requirements.txt 内容**：
`
flask>=2.0.0
flask-cors>=3.0.0
requests>=2.28.0
`

### 2.3 启动服务

**方式一：命令行启动**
`ash
python server.py
`

**方式二：双击启动脚本**
`
双击 start.bat
`

### 2.4 访问验证

浏览器打开：http://localhost:5000

看到页面加载即表示部署成功。

---

## 3. 配置说明

### 3.1 修改端口号

编辑 server.py，找到最后一行：

`python
app.run(host='0.0.0.0', port=5000, debug=True)
`

修改 port=5000 为你想要的端口，如 port=8080。

### 3.2 禁用调试模式

生产环境建议关闭debug模式：

`python
app.run(host='0.0.0.0', port=5000, debug=False)
`

### 3.3 修改缓存时间

编辑 server.py，找到：

`python
CACHE_TTL = 600  # 10分钟
`

修改为你想要的秒数。

## 4. 开机自启（Windows）

### 4.1 创建启动脚本

创建 startup.bat：
`at
@echo off
cd /d C:\stock-popularity
python server.py
`

### 4.2 添加到启动项

1. 按 Win+R，输入 shell:startup
2. 将 startup.bat 的快捷方式放入打开的文件夹

---

## 5. 开机自启（Linux）

### 5.1 创建服务文件

`ash
sudo nano /etc/systemd/system/stock-popularity.service
`

### 5.2 写入内容

`ini
[Unit]
Description=Stock Popularity Query Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/stock-popularity
ExecStart=/usr/bin/python3 server.py
Restart=always

[Install]
WantedBy=multi-user.target
`

### 5.3 启用服务

`ash
sudo systemctl enable stock-popularity
sudo systemctl start stock-popularity
`

## 6. 常见问题

### Q1: 端口被占用
`
OSError: [Errno 98] Address already in use
`
**解决方案**：修改端口号或关闭占用端口的程序

### Q2: 依赖安装失败
`
ERROR: Could not install packages
`
**解决方案**：
`ash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
`

### Q3: 无法访问外部API
**症状**：查询数据失败
**解决方案**：检查网络连接，确认可以访问以下地址：
- https://dq.10jqka.com.cn
- https://emappdata.eastmoney.com

### Q4: 编码错误
**症状**：显示乱码
**解决方案**：确保系统支持UTF-8编码
