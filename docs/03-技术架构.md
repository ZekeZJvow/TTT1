## 4. 数据流

### 4.1 人气榜数据流
`
用户点击查询
    │
    ▼
前端发起 fetch('/api/hotlist')
    │
    ▼
后端检查缓存（10分钟TTL）
    │
    ├─ 缓存命中 → 直接返回
    │
    └─ 缓存未命中 → 请求同花顺API
                        │
                        ├─ 成功 → 解析数据 → 请求东方财富补齐行业 → 缓存 → 返回
                        │
                        └─ 失败 → 降级到东方财富热股榜 → 返回
`

### 4.2 图表数据流
`
用户点击股票名称
    │
    ▼
前端打开模态框 → 请求分时/日K数据
    │
    ▼
后端根据类型请求不同接口：
    ├─ 分时 → 腾讯分时API
    └─ 日K → 新浪K线API
    │
    ▼
返回数据 → 前端ECharts渲染
`

## 5. 核心模块说明

### 5.1 交易日判定模块
- **功能**：判断当前日期是否为交易日，确定数据所属日期
- **规则**：
  - 周末：回溯到上周五
  - 盘前（09:30前）：使用上一交易日数据
  - 盘中（09:30-15:00）：使用上一交易日数据
  - 盘后（15:00后）：使用当日数据
- **限制**：当前仅排除周末，未接入法定节假日

### 5.2 数据处理模块
- **连板数**：解析同花顺popularity_tag字段
- **梯队划分**：根据排名划分为Top10/Top20/Top30
- **异动解读**：优先取analyse_title，其次analyse，最后topic.title
- **涨跌幅**：基于前一日收盘价计算

### 5.3 降级机制
- **触发条件**：同花顺API请求失败或返回异常
- **降级目标**：东方财富热股榜API
- **影响**：部分字段（连板数、异动解读）不可用，显示为"无"

## 6. 安全与限制

### 6.1 安全措施
- SSL证书验证已禁用（第三方接口兼容性）
- 内存缓存限制频繁请求
- 前端不直连第三方API（通过后端代理）

### 6.2 已知限制
- 交易日历不完整（未含法定节假日）
- 概念标签非严格行业分类
- 无用户认证机制
- 无数据持久化（重启服务缓存清空）
