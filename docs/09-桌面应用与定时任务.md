# 桌面应用与定时任务

> 把系统做成「桌面双击即用的应用」，并支持每天定时自动启动。

---

## 一、交付物

| 文件 | 位置 | 作用 |
|------|------|------|
| `A股人气雷达.lnk` | 桌面 | 双击启动（无控制台窗口） |
| `launch_app.vbs` | 项目根目录 | 启动器：探测服务 → 未启动则拉起 → 打开应用窗口 |
| `serve.py` | 项目根目录 | 后台常驻服务入口（无调试、多线程） |
| `icon.ico` | 项目根目录 | 应用图标（红色圆角 + 上升折线） |
| `service.log` | 项目根目录 | 后台服务日志（运行时生成） |

---

## 二、双击启动流程

```
双击桌面「A股人气雷达」
        │
        ├─ 探测 http://127.0.0.1:5000  已就绪？
        │        ├─ 是 → 直接打开窗口（不重复启服务）
        │        └─ 否 → 隐藏窗口启动 serve.py，最多等 45 秒
        │
        └─ 用 Chrome/Edge 的 --app 模式打开
             （无地址栏/标签栏，外观等同独立桌面应用）
```

**优先使用 Chrome，其次 Edge，都没有则用默认浏览器。**

## 三、每日 8:00 定时启动

已注册 Windows 计划任务：

| 项目 | 值 |
|------|-----|
| 任务名 | `A股人气雷达-每日8点启动` |
| 触发 | 每天 08:00 |
| 运行身份 | 当前用户（仅在登录时运行） |
| 执行 | `wscript.exe launch_app.vbs` |
| 补跑 | 已开启（错过时间会自动补跑） |

### 常用操作

```powershell
# 查看状态与下次运行时间
Get-ScheduledTaskInfo -TaskName "A股人气雷达-每日8点启动"

# 立即运行一次
Start-ScheduledTask -TaskName "A股人气雷达-每日8点启动"

# 暂停 / 恢复
Disable-ScheduledTask -TaskName "A股人气雷达-每日8点启动"
Enable-ScheduledTask  -TaskName "A股人气雷达-每日8点启动"

# 删除
Unregister-ScheduledTask -TaskName "A股人气雷达-每日8点启动" -Confirm:$false
```

### 改成「仅工作日 8:00」

若只想在交易日启动，把触发器换成每周一至周五：

```powershell
$t = Get-ScheduledTask -TaskName "A股人气雷达-每日8点启动"
$t.Triggers = @()
Set-ScheduledTask -TaskName "A股人气雷达-每日8点启动" -Trigger (New-ScheduledTaskTrigger `
    -Weekly -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -At 8:00AM)
```

## 四、手动管理服务

```powershell
# 启动（后台，无窗口）
Start-Process "$PWD\venv\Scripts\pythonw.exe" -ArgumentList "serve.py" -WorkingDirectory "$PWD" -WindowStyle Hidden

# 停止
Get-CimInstance Win32_Process -Filter "Name='pythonw.exe'" | ForEach-Object { taskkill /F /PID $_.ProcessId }

# 换端口
$env:PORT = "8080"; .\venv\Scripts\python.exe serve.py

# 看日志
Get-Content service.log -Tail 30
```

## 五、说明与限制

- `serve.py` 关闭了 Flask 调试模式与自动重载 —— 调试模式会派生 2 个进程，不适合常驻
- 已开启 `threaded=True`，扫描（约 30 秒）不会阻塞其他请求
- 计划任务为「用户登录时运行」，需保持当前用户已登录；若要开机免登录运行，需改用「不管用户是否登录都要运行」并保存密码
- 若端口 5000 被其他程序占用，启动器会探测失败但不会重复启动服务；请先释放端口或改 `PORT`
