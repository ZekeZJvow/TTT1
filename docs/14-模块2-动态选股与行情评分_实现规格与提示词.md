> 目的：把「动态选股」与「行情评分」**无损复刻**到另一个开发环境（workbuddy）。
> 本文档 = 功能说明 + 逐条实现规格 + 验收断言 + 一段可直接粘贴的提示词。
> 口径基准：本机实际运行代码（2026-10-14 核对）。

# Part A · 功能说明（人读）

## A1. 一句话
输入任意交易日，**全市场扫描**出当天「**首板启动股**」——即**昨天还没涨停、今天盘中冲高超过 9%** 的票；再和东财涨停池做**语义交叉校验**，并给出**行情评分**。

## A2. 它回答什么问题
> 今天有哪些票是「**刚刚启动**」的？（不是连板高位股，而是首板起点）

## A3. 三个条件（核心口径）
| 条件 | 内容 | 含义 |
|---|---|---|
| **条件①** | 前一交易日 D-1 的**首次涨停时间取反** → D-1 **全天未触及涨停价** | 主动**剔除连板股**（昨天已涨停的不算"刚启动"） |
| **条件②** | `(D 最高价 − D-1 收盘价) ÷ D-1 收盘价 > 0.09` | 今日**盘中冲高 > 9%** |
| **条件③** | **沪深主板** 且 **非 ST** | 股票池范围 |

## A4. 输出
- **漏斗**：全市场 → 条件② → +条件① → 其中封住涨停 / 其中冲高未封 / 被条件①剔除
- **封板率 = 行情评分**：`封住涨停数 ÷ 入选池数 × 100`
- **三张明细表**：入选池 / 冲高未封 / 被条件①剔除（可切换、全列可排序）
- **语义交叉校验**：用「价格法」与「东财涨停池法」互相验证，输出冲突条数
- **一键导出 HTML 报告**
- **行情评分走势**：把每天的评分与涨跌家数、成交额画成趋势图

## A5. 重要口径提醒
1. **"首次涨停时间取反" = D-1 没有涨停**。这是整条公式的灵魂：它把连板股挡在门外。
2. 用「**最高价**」判定条件②，所以入选的票**不一定封板**——约 1/3 是炸板（冲高回落）。
3. 盘中跑 = 实时最高价 → 信号是"此刻正在冲板"；盘后跑 = 准涨停复盘。**两者含义不同**。
4. 只覆盖**沪深主板**（600/601/603/605/000/001/002/003），不含创业板/科创板（20cm）与北交所。

## B1. 常量（原样照抄）
```
SH_MAIN = ("600", "601", "603", "605")
SZ_MAIN = ("000", "001", "002", "003")
WORKERS = 24            # 并发抓日K的线程数
THRESHOLD = 0.09        # 条件② 阈值 9%
PRICE_EPS = 0.005       # 价格比较容差（半分钱）
```
- `round2(x)`：四舍五入到 **0.01**，用 `Decimal(str(x)).quantize(Decimal("0.01"), ROUND_HALF_UP)`（**必须用 Decimal，避免浮点误差**）
- `fmt_hhmmss(v)`：`92500 → "09:25:00"`（整数补零 6 位再插冒号）

## B2. 数据源（4 个接口，含完整 URL 与请求头）

### B2.1 日K（新浪）——**扫描主通道**
```
GET https://quotes.sina.cn/cn/api/jsonp_v2.php/var/CN_MarketDataService.getKLineData
    ?symbol=sh600000&scale=240&ma=no&datalen=120
```
- 返回 JSONP：取**第一个 `(` 到最后一个 `)`** 之间的内容做 `json.loads`
- 每根 K：`{day, open, high, low, close, volume}`，**按日期升序**

- 重试 3 次，间隔 `0.25*(i+1)` 秒；失败返回 `[]`

### B2.2 股票列表（新浪）——沪深主板非ST全量
```

    Market_Center.getHQNodeData?page={p}&num=100&sort=symbol&asc=1&node={sh_a|sz_a}
```
- 依次翻 `node=sh_a` 与 `node=sz_a`，`page` 从 1 递增（上限 80 页），空页停止
- 每条取 `symbol`(如 sh600000) / `code`(600000) / `name`

- `is_mainboard`：sh 前缀取第 3-5 位判断是否在 SH_MAIN；sz 同理
- `is_st(name)`：`name` 去掉空格转大写含 `"ST"`，**或**名称含 `"退"`

### B2.3 涨停池 / 炸板池（东方财富）——校验与信息补全
```
kind = "ZT" -> https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=600&sort=fbt%3Aasc&date=YYYYMMDD
kind = "ZB" -> 同上，换成 getTopicZBPool
```
- 请求头：UA + `Referer: https://quote.eastmoney.com/`，`verify=False`，timeout=15
- 取 `data.pool[]`，按 6 位代码（`c` 左补零）建索引，字段映射：
  | 源字段 | 含义 |
  |---|---|
  | `fbt` | 首次封板时间 → `fmt_hhmmss` |
  | `lbt` | 最后封板时间 → `fmt_hhmmss` |
  | `zbc` | 炸板次数 |
  | `lbc` | 连板数 |
  | `hybk` | 所属行业板块 |
  | `hs` | 换手率 |
  | `amount` | 成交额 |

### B2.4 新浪行业映射——给"不在涨停池里"的行补行业
```

```

- 用 12 线程并发；**进程内缓存**（只构建一次）
- `fill_sectors(rows)`：只给 `sector` 为空的行补；返回补齐条数

## B3. 单只股票推算 `evaluate(k, d2, d1, d)`

> `k` = 该股票日K列表（升序）；`d2`=D-2、`d1`=D-1、`d`=D 的日期字符串

```
1. 建 map: day -> bar；若 d2 / d1 / d 任一缺失 -> 返回 None（停牌或数据不足）
2. 取数：
   c2 = D-2 收盘      c1 = D-1 收盘      h1 = D-1 最高
   o0,h0,l0,c0 = D 的开/高/低/收        v0 = D 的成交量
3. 若 c1<=0 或 c2<=0 -> 返回 None
4. 涨停价：
   limit1 = round2(c2 * 1.1)      # D-1 涨停价
   limit0 = round2(c1 * 1.1)      # D   涨停价
5. 三个状态：
   touchedPrev = (h1 >= limit1 - 0.005)              # D-1 触及过涨停
   sealed      = (c0 >= limit0 - 0.005)              # D 封住涨停
   broke       = (not sealed) and (h0 >= limit0 - 0.005)   # D 炸板
6. 指标（全部保留 2 位小数）：
   gainHigh  = (h0 - c1) / c1 * 100      # 最高涨幅
   gainClose = (c0 - c1) / c1 * 100      # 收盘涨跌幅
   amplitude = (h0 - l0) / c1 * 100      # 振幅
   prevGain  = (c1 - c2) / c2 * 100      # D-1 涨跌幅
   amountEst = v0 * (o0 + h0 + l0 + c0) / 4     # 成交额估算（元），注意这不是交易所口径
7. 两个条件：
   cond2 = gainHigh > 0.09        # 注意：用比例比较（> 0.09），不是 > 9
   cond1 = not touchedPrev
```

返回 dict（字段名固定）：`code, name, closeD2, closePrev, limitPrev, high, low, open, close, limit,
gainHigh, gainClose, amplitude, amountEst, volume, touchedPrev, sealed, broke, cond2, cond1, prevGain`

## B4. 主流程 `run_screen(target, progress=None, resume=True)`

### 步骤 1 · 日期推导
1. `tdays = get_trading_days(400)`（上证指数 sh000001 的日K日期列表，升序）
2. 若 `target` 不在其中 → 返回失败，附 `hint`（最近 6 个可用交易日）与 `recentDays`（最近 10 个，倒序）
3. `i = tdays.index(target)`；若 `i < 2` → 返回失败「历史数据不足，无法推导前两个交易日」
4. `d = target`，`d1 = tdays[i-1]`，`d2 = tdays[i-2]`

### 步骤 2 · 日K长度
```
back    = (今天 - d2) 的天数
datalen = clamp( round(back * 7 / 5) + 25, 12, 900 )     # 7/5 是因为一周 7 天只有 5 个交易日
```

### 步骤 3 · 股票池
`uni = get_mainboard_universe()`（约 3050 只）；为 0 → 报错「股票列表获取失败」

### 步骤 4 · 断点续传
- `resume=True`：`done_codes = load_scan_codes(target)`；`todo = uni 中 code 不在 done_codes 的`
- `resume=False`：`clear_scan(target)`；`todo = uni`
- `resumed_from = total - len(todo)`

### 步骤 5 · 并发扫描
- `ThreadPoolExecutor(max_workers=24)`，对每只股票抓 `datalen` 根日K
- 取数失败（网络/停牌）→ **不落暂存**，下次运行会重试
- `evaluate` 返回 None → 记为 `{code, name, skipped: True}`
- 否则把 `code` / `name` 补进结果
- **每累积 300 条 flush 一次** 到暂存表（`save_scan_stocks`）

### 步骤 6 · 重建结果
`results = load_scan_results(target)`（从暂存表读，保证"断点续传"与"一次扫完"结果等价）

### 步骤 7 · 落库当日全市场日K
把 results 的 `open/high/low/close/volume/prev_close(=closePrev)` 写入 `daily_kline`（source=`sina`）

### 步骤 8 · 分组
```
cond2   = [r for r in results if r.cond2]          # 今日冲高 > 9%
final   = [r for r in cond2   if r.cond1]          # + 昨日未触及涨停  → 入选池
sealed  = [r for r in final   if r.sealed]         # 其中：封住涨停
broken  = [r for r in final   if not r.sealed]     # 其中：冲高未封（炸板）
removed = [r for r in cond2   if not r.cond1]      # 被条件①剔除（昨日涨停股）
```

### 步骤 9 · 语义交叉校验（东财池）
取 4 份池数据：`ZT/ZB @ d` 与 `ZT/ZB @ d1`。

**逐行补信息**（对 results 每一只）：
| 命中 | firstSeal | lastSeal | boards | sector | poolState |
|---|---|---|---|---|---|
| 在 `ZT[d]` | 池里的首次封板时间 | 池里的最后封板时间 | 连板数 | 行业 | `"涨停"` |
| 在 `ZB[d]` | 池里的首次封板时间 | `""` | None | 行业 | `"炸板"` |
| 都不在 | `""` | `""` | None | `""` | `""` |

**冲突检测**（只对 `cond2` 的股票）：
```
prevPool = set(ZT[d1].keys()) | set(ZB[d1].keys())
byPrice  = r.touchedPrev                 # 价格法：D-1 最高价 >= D-1 涨停价
byPool   = r.code in prevPool            # 池法：D-1 出现在东财涨停/炸板池
两者不一致 -> 记入 mismatch
```

### 步骤 10 · 行业补全
`fill_sectors(final + broken + removed)` → 给 sector 为空的行用新浪行业映射补

### 步骤 11 · 排序与收尾
- 去掉 `final` 行里的 `cond2` / `cond1` 字段
- `final` / `broken` / `removed` **都按 `gainHigh` 降序**

### 步骤 12 · 返回结构（字段名固定）
```json
{
  "success": true,
  "target": "2026-10-13", "prevDay": "2026-10-10", "prevDay2": "2026-10-09",
  "universe": 3050, "scanned": 3044, "suspended": 6,
  "funnel": {"cond2": 76, "final": 76, "sealed": 28, "broken": 48, "removedByCond1": 16},
  "sealedRate": 36.8,
  "rows": [ /* 入选池 */ ], "brokenRows": [ /* 冲高未封 */ ], "removedRows": [ /* 被剔除 */ ],
  "validation": {"poolZtCount":43, "poolZbCount":32, "prevPoolCount":64, "mismatch":[], "errors":[]},
  "sectorFilled": 0, "resumedFrom": 0, "scanStaging": {...},
  "elapsed": 61.4, "threshold": 0.09,
  "source": "新浪财经（日K） + 东方财富（涨停/炸板池校验）",
  "collectedAt": "2026-10-13 15:31:02"
}
```

### B5. 行情评分（页头那个分数）
```
行情评分 = sealedRate = round( len(sealed) / len(final) * 100, 1 )      # final 为 0 时 = 0
```
> 含义：**今天冲高 >9% 的票里，有多少最终真的封住了涨停**。分越高 = 当天市场情绪越强、追涨越容易封板。

## B6. 行情评分的历史序列（"行情评分走势"模块）

### B6.1 离线口径 `compute_seal_stats`
> 不依赖当天是否真的跑过扫描，直接用**本地日K**反推每一天的评分，与真实选股结果逐位核对一致。

```
1. 完整交易日：daily_kline 中某日 change_pct 非空的行数 >= 2000 才算
2. ST 名单：stock 表中 is_st=1 或名称含 "ST" 的代码集合
3. 对每个待算日 d（需要 pos[d] >= 2，即至少有两个更早的完整交易日）：
   取 d1 = 上一个完整交易日，d2 = 上两个
   遍历当日沪深主板（stock_code 前 3 位 ∈ 600/601/603/605/000/001/002/003）的股票：
      跳过 ST
      跳过 c1/c2/hi/h1 缺失
      若 h1 >= round2(c2*1.1) - 0.005  -> 跳过（昨日触及涨停）
      若 (hi - c1)/c1 > 0.09           -> final += 1
         且 cl >= round2(c1*1.1) - 0.005  -> sealed += 1
   score = round(sealed / final * 100, 1)      # final=0 时 score = None
   平盘/上涨/下跌家数 = 全市场按 change_pct 分别 >0 / <0 / =0 计数
4. 只算"缺的日子"（除非 force），落库到 market_seal_stats
5. 每次最多回看 460 天
```

### B6.2 读接口的口径优先级
- **行情评分**：优先用该日**真实选股结果**的 `sealedRate`（更权威），否则用离线统计的 score
- **涨跌家数**：优先 `market_breadth`（**沪深京全部 A 股**口径，实时抓取，与同花顺"涨跌分布"一致），否则用离线全市场统计
- **成交额**：`market_turnover`（**沪深两市**，沪市 + 深市）
- 返回字段（升序）：`{date, up, down, flat, final, sealed, score, src, breadth_src, amount, amount_prev, amount_diff}`
- 带 **120 秒内存缓存**；若统计落后于最新日K → **后台线程补算**，不阻塞本次响应

## B7. HTTP 接口契约

### B7.1 `POST/GET /api/screen/start`
- 参数 `date`（必填，YYYY-MM-DD）
- 后台线程执行 `run_screen`，立即返回；进度用 `/api/screen/status` 轮询
- **同一天同一任务已在跑 → 不重复启动**

### B7.2 `GET /api/screen/status?date=...`
返回 `{success, state: running|done|error, done, total, message, result?}`（state 为 done/error 时带 result）

### B7.3 `GET /api/screen?date=...`
同步返回该日扫描结果（内存缓存 → 本地库 → 无则报错）

### B7.4 `GET /api/screen/report?date=...`
返回**独立 HTML 报告**（`Content-Type: text/html; charset=utf-8`）；该日无结果 → 404 + 提示文案

### B7.5 `GET /api/market-score?date=...`
- 只读，**绝不触发扫描**
- 默认日期 = 当前场次交易日；若该日无结果 → **回退到最近一次有结果的日期**
- 返回 `{success, date, score, sealed, final}`；无数据时 `score: null`

### B7.6 `GET /api/market-history?days=45&start=&end=`
- `days` 夹紧 5~120；`start/end` 用于月份/区间筛选
- 窗口：默认 120 天；给了 `start` 就按 `(今天-start)+30` 扩展（上限 500 天）
- 返回 `{success, days, start, end, rows, count, months}`（`months` 为有数据的月份列表）

### B7.7 落库表
| 表 | 用途 | 关键字段 |
|---|---|---|
| `daily_kline` | 全市场日K | stock_code, trade_date, open/high/low/close/prev_close/change_pct/volume/amount |
| `limit_up_pool` | 涨停/炸板池 | trade_date, stock_code, kind(ZT/ZB), first_seal, last_seal, boards, sector |

## B8. 前端规格

### B8.1 筛选面板
- 标题「动态选股 · 参数化扫描」+ 说明（含高亮：**推导前一交易日**、**扫描全市场**、**首板启动股**、**语义交叉校验**）
- 条件卡片三条：`条件① 前一交易日(D-1) 首次涨停时间取反 → D-1 全天未触及涨停价` / `条件② (D 最高价 − D-1 收盘价) ÷ D-1 收盘价 > 0.09` / `条件③ 沪深主板 且 非 ST`
- 目标日期输入（默认**最近交易日**，自动跳过周末与节假日）+ 「🎯 开始扫描」按钮
- 提示文案：`首次扫描全市场约需 30 秒，同一日期结果会缓存，重复查询秒出。`

### B8.2 结果区（自上而下）
1. **元信息条**：数据所属交易日 / 前一交易日 / 全市场(扫描/暂停) / 扫描完成耗时
2. **进度条**：`已扫描 N/M`，进度百分比
3. **选股漏斗**：`全部沪深主板非ST → 条件② 盘中最高涨幅>9% → +条件① 昨日未涨停(入选) → 其中 封住涨停 / 其中 冲高未封 / 被条件①剔除(昨日涨停股)`，每行带数量与条形；底部 **封板率 xx.x%（sealed / final）**
4. **语义交叉校验卡片**：`D 涨停池 N 只 · D 炸板池 N 只 · D-1 涨停+炸板池 N 只`；一行结论——
   - 无冲突：`✅ 价格法（最高价 ≥ 涨停价）与涨停池法结果完全一致，冲突 0 处`
   - 有冲突：列出冲突股票

## B9. 异常与边界（全部必须处理）
1. 目标日期不是交易日 → 明确报错 + 给出最近可用交易日
2. 历史数据不足（前两个交易日推不出来）→ 报错
3. 股票列表接口失败 → 报错
4. 单只股票日K取数失败 / 停牌 → **不落暂存**，下次重试

6. 东财池接口失败 → 主流程继续（校验部分记 errors）
7. 入选池为 0 → 评分记 0，不报错

9. 涨幅阈值用**比例**（> 0.09）比较，不要用百分数（> 9）
10. 断点续传：flush 批量 300；`resume=False` 时先清空暂存

```
请实现一个"A股动态选股（参数化扫描）+ 行情评分"Web 模块。要求功能完整、口径无偏差，按下面规格逐条实现，最后按"验收测试"自测并给出通过证据。

【技术栈】Python 3.12 + Flask 后端（选股引擎独立成 screener.py）+ 原生 HTML/CSS/JS + ECharts 前端 + SQLite 存储。

【一、常量（原样照抄）】
SH_MAIN=("600","601","603","605")  SZ_MAIN=("000","001","002","003")
WORKERS=24  THRESHOLD=0.09  PRICE_EPS=0.005
round2(x)=用 Decimal(str(x)).quantize(Decimal("0.01"), ROUND_HALF_UP) 四舍五入到分（必须用 Decimal，避免浮点误差）
fmt_hhmmss(92500) -> "09:25:00"

【二、数据源（4 个，URL 完整）】
1) 日K（扫描主通道）：
   GET https://quotes.sina.cn/cn/api/jsonp_v2.php/var/CN_MarketDataService.getKLineData?symbol=sh600000&scale=240&ma=no&datalen=120
   返回 JSONP，取第一个 "(" 到最后一个 ")" 之间内容做 json.loads；每根 K 含 day/open/high/low/close/volume，按日期升序。
   请求头 UA(Chrome) + Referer: https://finance.sina.com.cn/ ；重试 3 次（间隔 0.25*(i+1) 秒），失败返回 []。
2) 沪深主板非ST股票列表：
   GET https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodeData?page={p}&num=100&sort=symbol&asc=1&node={sh_a|sz_a}
   翻 sh_a 与 sz_a，page 从 1 到最多 80，空页停止；取 symbol(如 sh600000)/code(600000)/name；
   过滤：主板代码前缀 且 非ST；按 code 排序。（约 3050 只）
   is_st(name) = 去空格转大写含 "ST" 或 名称含 "退"
3) 涨停池/炸板池（东财，用于校验与补全）：
   kind=ZT -> https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=600&sort=fbt%3Aasc&date=YYYYMMDD

   请求头 UA + Referer: https://quote.eastmoney.com/ ，verify=False，timeout=15；取 data.pool[]，按 6 位代码（c 左补零）建索引；
   字段：fbt->firstSeal(用 fmt_hhmmss)、lbt->lastSeal、zbc->breakCount、lbc->boards、hybk->sector、hs->turnover、amount。
4) 新浪行业映射（给不在涨停池的行补行业）：
   GET .../Market_Center.getHQNodes 取 48 个行业板块（在返回的嵌套数组里找第一个以 "玻璃行业" 开头的子列表）；
   每个板块翻 1~3 页 GET .../Market_Center.getHQNodeData?page={p}&num=100&node={行业node}，取 symbol[-6:] -> 行业名；
   12 线程并发，进程内缓存；fill_sectors(rows) 只补 sector 为空的行并返回补齐条数。

【三、单只股票推算 evaluate(k, d2, d1, d)】
k 是该股日K（升序），d2/d1/d 是 D-2/D-1/D 的日期字符串。
1. 建 map(day->bar)；d2/d1/d 任一缺失 -> 返回 None（停牌或数据不足）
2. c2=D-2收盘, c1=D-1收盘, h1=D-1最高；o0,h0,l0,c0,v0=D 的开/高/低/收/量；c1<=0 或 c2<=0 -> None
3. limit1=round2(c2*1.1)（D-1 涨停价）；limit0=round2(c1*1.1)（D 涨停价）
4. touchedPrev = (h1 >= limit1 - 0.005)；sealed = (c0 >= limit0 - 0.005)；broke = (not sealed) and (h0 >= limit0 - 0.005)
5. gainHigh=(h0-c1)/c1*100  gainClose=(c0-c1)/c1*100  amplitude=(h0-l0)/c1*100  prevGain=(c1-c2)/c2*100（均保留 2 位）
   amountEst = v0*(o0+h0+l0+c0)/4（元，估算口径）
6. cond2 = gainHigh > 0.09（注意是比例，不是百分数）；cond1 = not touchedPrev
返回字段名固定：code,name,closeD2,closePrev,limitPrev,high,low,open,close,limit,gainHigh,gainClose,amplitude,amountEst,volume,touchedPrev,sealed,broke,cond2,cond1,prevGain

【四、主流程 run_screen(target)】
1) tdays=get_trading_days(400)（上证指数 sh000001 日K日期升序）；target 不在其中 -> 失败并给 hint(最近6个) 与 recentDays(最近10个倒序)；i=tdays.index(target)，i<2 -> 失败
2) d=target, d1=tdays[i-1], d2=tdays[i-2]
3) datalen = clamp(round((今天-d2).days * 7/5) + 25, 12, 900)
4) uni=get_mainboard_universe()；为 0 -> 报错
5) 断点续传：resume=True 时 todo = uni 中未扫过的（load_scan_codes）；否则先 clear_scan
6) ThreadPoolExecutor(max_workers=24) 并发抓日K；取数失败不落暂存（下次重试）；evaluate 返回 None 记 {code,name,skipped:true}；每累积 300 条 flush 到暂存表
7) results = load_scan_results(target)（从暂存重建，保证与一次扫完等价）
8) 把 results 写入 daily_kline（open/high/low/close/volume/prev_close=closePrev）
9) 分组：cond2=[cond2 为真]；final=[cond2 且 cond1]；sealed=[final 且 sealed]；broken=[final 且非 sealed]；removed=[cond2 且非 cond1]
10) 取东财池 ZT/ZB @ d 和 @ d1，对每只股票补 firstSeal/lastSeal/boards/sector/poolState（在 ZT[d] -> "涨停"；在 ZB[d] -> "炸板" 且 lastSeal="" boards=None；都不在 -> 全空）
11) 冲突检测（只对 cond2）：byPrice=r.touchedPrev vs byPool=(code 在 ZT[d1]∪ZB[d1])，不一致记入 mismatch
12) fill_sectors(final+broken+removed)；final 行去掉 cond2/cond1；三组都按 gainHigh 降序
13) 返回：{success,target,prevDay,prevDay2,universe,scanned,suspended,funnel:{cond2,final,sealed,broken,removedByCond1},sealedRate,rows,brokenRows,removedRows,validation:{poolZtCount,poolZbCount,prevPoolCount,mismatch,errors},sectorFilled,resumedFrom,scanStaging,elapsed,threshold,source,collectedAt}
14) 行情评分 = sealedRate = round(len(sealed)/len(final)*100, 1)（final 为 0 时 0）

【五、行情评分的历史序列（离线口径，不依赖当天跑没跑过扫描）】compute_seal_stats
1) 完整交易日 = daily_kline 中该日 change_pct 非空行数 >= 2000
2) ST 名单来自 stock 表（is_st=1 或名称含 ST）
3) 对每个待算日 d（需至少有两个更早的完整交易日）：遍历当日沪深主板股票，跳过 ST 与 c1/c2/hi/h1 缺失；
   若 h1 >= round2(c2*1.1)-0.005 -> 跳过；若 (hi-c1)/c1>0.09 -> final+=1，且当 cl >= round2(c1*1.1)-0.005 时 sealed+=1；
   score = round(sealed/final*100, 1)（final=0 时 None）；涨跌平家数按当日全市场 change_pct 计数
4) 只算缺的日子，落库 market_seal_stats；最多回看 460 天
```
