## 2. 功能详细说明

### 2.1 数据查询模块

#### 人气榜查询
- **功能**：获取同花顺个股人气榜Top30数据
- **触发方式**：用户手动点击「查询」按钮
- **数据源**：同花顺API
- **降级源**：东方财富热股榜API

#### 交易日判定
- **功能**：根据查询时刻确定数据所属交易日
- **规则**：
  | 时刻 | 数据所属日 |
  |------|------------|
  | 交易日 09:30前 | 上一交易日 |
  | 交易日 09:30-15:00 | 上一交易日 |
  | 交易日 15:00后 | 当日 |
  | 周末 | 最近交易日 |

---

### 2.2 图表展示模块

#### 分时线
- **数据源**：腾讯分时API
- **显示内容**：价格走势、成交金额
- **交互功能**：鼠标悬停显示涨跌幅、均价、昨收

#### 日K线
- **数据源**：新浪K线API
- **显示内容**：K线图、成交金额
- **交互功能**：缩放、鼠标悬停显示OHLC数据

---

### 2.3 数据处理规则

#### 连板数
| 输入（popularity_tag） | 输出 |
|------------------------|------|
| "2天2板" | "2连板（2天2板）" |
| "首板涨停" | "首板（当日）" |
| 无 | "无" |

#### 梯队划分
| 排名区间 | 梯队 |
|----------|------|
| 1-10 | 第一梯队·人气Top10 |
| 11-20 | 第二梯队·人气Top20 |
| 21-30 | 第三梯队·人气Top30 |

#### 涨跌幅
- **公式**：(当日收盘价 - 前一日收盘价) / 前一日收盘价 × 100%
- **特殊处理**：一字板使用前一日收盘价计算

#### 异动解读优先级
1. analyse_title（分析标题）
2. analyse（分析正文，截取25字）
3. topic.title（热点话题）
4. "无"
