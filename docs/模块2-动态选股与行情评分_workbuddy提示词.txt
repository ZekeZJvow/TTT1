请实现一个"A股动态选股（参数化扫描）+ 行情评分"Web 模块。要求功能完整、口径无偏差，按下面规格逐条实现，最后按"验收测试"自测并给出通过证据。

【技术栈】Python 3.12 + Flask 后端（选股引擎独立成 screener.py）+ 原生 HTML/CSS/JS + ECharts 前端 + SQLite 存储。

【一、常量（原样照抄）】
SH_MAIN=("600","601","603","605")  SZ_MAIN=("000","001","002","003")
WORKERS=24  THRESHOLD=0.09  PRICE_EPS=0.005
round2(x)=用 Decimal(str(x)).quantize(Decimal("0.01"), ROUND_HALF_UP) 四舍五入到分（必须用 Decimal，避免浮点误差）
fmt_hhmmss(92500) -> "09:25:00"

【二、数据源（4 个，URL 完整）】
1) 日K（扫描主通道）：
   GET https://quotes.sina.cn/cn/api/jsonp_v2.php/var/CN_MarketDataService.getKLineData?symbol=sh600000&scale=240&ma=no&datalen=120
   返回 JSONP，取第一个 "(" 到最后一个 ")" 之间内容做 json.loads；每根 K 含 day/open/high/low/close/volume，按日期升序。
   请求头 UA(Chrome) + Referer: https://finance.sina.com.cn/ ；重试 3 次（间隔 0.25*(i+1) 秒），失败返回 []。
2) 沪深主板非ST股票列表：
   GET https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodeData?page={p}&num=100&sort=symbol&asc=1&node={sh_a|sz_a}
   翻 sh_a 与 sz_a，page 从 1 到最多 80，空页停止；取 symbol(如 sh600000)/code(600000)/name；
   过滤：主板代码前缀 且 非ST；按 code 排序。（约 3050 只）
   is_st(name) = 去空格转大写含 "ST" 或 名称含 "退"
3) 涨停池/炸板池（东财，用于校验与补全）：
   kind=ZT -> https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=600&sort=fbt%3Aasc&date=YYYYMMDD
   kind=ZB -> 同上换 getTopicZBPool
   请求头 UA + Referer: https://quote.eastmoney.com/ ，verify=False，timeout=15；取 data.pool[]，按 6 位代码（c 左补零）建索引；
   字段：fbt->firstSeal(用 fmt_hhmmss)、lbt->lastSeal、zbc->breakCount、lbc->boards、hybk->sector、hs->turnover、amount。
4) 新浪行业映射（给不在涨停池的行补行业）：
   GET .../Market_Center.getHQNodes 取 48 个行业板块（在返回的嵌套数组里找第一个以 "玻璃行业" 开头的子列表）；
   每个板块翻 1~3 页 GET .../Market_Center.getHQNodeData?page={p}&num=100&node={行业node}，取 symbol[-6:] -> 行业名；
   12 线程并发，进程内缓存；fill_sectors(rows) 只补 sector 为空的行并返回补齐条数。

【三、单只股票推算 evaluate(k, d2, d1, d)】
k 是该股日K（升序），d2/d1/d 是 D-2/D-1/D 的日期字符串。
1. 建 map(day->bar)；d2/d1/d 任一缺失 -> 返回 None（停牌或数据不足）
2. c2=D-2收盘, c1=D-1收盘, h1=D-1最高；o0,h0,l0,c0,v0=D 的开/高/低/收/量；c1<=0 或 c2<=0 -> None
3. limit1=round2(c2*1.1)（D-1 涨停价）；limit0=round2(c1*1.1)（D 涨停价）
4. touchedPrev = (h1 >= limit1 - 0.005)；sealed = (c0 >= limit0 - 0.005)；broke = (not sealed) and (h0 >= limit0 - 0.005)
5. gainHigh=(h0-c1)/c1*100  gainClose=(c0-c1)/c1*100  amplitude=(h0-l0)/c1*100  prevGain=(c1-c2)/c2*100（均保留 2 位）
   amountEst = v0*(o0+h0+l0+c0)/4（元，估算口径）
6. cond2 = gainHigh > 0.09（注意是比例，不是百分数）；cond1 = not touchedPrev
返回字段名固定：code,name,closeD2,closePrev,limitPrev,high,low,open,close,limit,gainHigh,gainClose,amplitude,amountEst,volume,touchedPrev,sealed,broke,cond2,cond1,prevGain

【四、主流程 run_screen(target)】
1) tdays=get_trading_days(400)（上证指数 sh000001 日K日期升序）；target 不在其中 -> 失败并给 hint(最近6个) 与 recentDays(最近10个倒序)；i=tdays.index(target)，i<2 -> 失败
2) d=target, d1=tdays[i-1], d2=tdays[i-2]
3) datalen = clamp(round((今天-d2).days * 7/5) + 25, 12, 900)
4) uni=get_mainboard_universe()；为 0 -> 报错
5) 断点续传：resume=True 时 todo = uni 中未扫过的（load_scan_codes）；否则先 clear_scan
6) ThreadPoolExecutor(max_workers=24) 并发抓日K；取数失败不落暂存（下次重试）；evaluate 返回 None 记 {code,name,skipped:true}；每累积 300 条 flush 到暂存表
7) results = load_scan_results(target)（从暂存重建，保证与一次扫完等价）
8) 把 results 写入 daily_kline（open/high/low/close/volume/prev_close=closePrev）
9) 分组：cond2=[cond2 为真]；final=[cond2 且 cond1]；sealed=[final 且 sealed]；broken=[final 且非 sealed]；removed=[cond2 且非 cond1]
10) 取东财池 ZT/ZB @ d 和 @ d1，对每只股票补 firstSeal/lastSeal/boards/sector/poolState（在 ZT[d] -> "涨停"；在 ZB[d] -> "炸板" 且 lastSeal="" boards=None；都不在 -> 全空）
11) 冲突检测（只对 cond2）：byPrice=r.touchedPrev vs byPool=(code 在 ZT[d1]∪ZB[d1])，不一致记入 mismatch
12) fill_sectors(final+broken+removed)；final 行去掉 cond2/cond1；三组都按 gainHigh 降序
13) 返回：{success,target,prevDay,prevDay2,universe,scanned,suspended,funnel:{cond2,final,sealed,broken,removedByCond1},sealedRate,rows,brokenRows,removedRows,validation:{poolZtCount,poolZbCount,prevPoolCount,mismatch,errors},sectorFilled,resumedFrom,scanStaging,elapsed,threshold,source,collectedAt}
14) 行情评分 = sealedRate = round(len(sealed)/len(final)*100, 1)（final 为 0 时 0）

【五、行情评分的历史序列（离线口径，不依赖当天跑没跑过扫描）】compute_seal_stats
1) 完整交易日 = daily_kline 中该日 change_pct 非空行数 >= 2000
2) ST 名单来自 stock 表（is_st=1 或名称含 ST）
3) 对每个待算日 d（需至少有两个更早的完整交易日）：遍历当日沪深主板股票，跳过 ST 与 c1/c2/hi/h1 缺失；
   若 h1 >= round2(c2*1.1)-0.005 -> 跳过；若 (hi-c1)/c1>0.09 -> final+=1，且当 cl >= round2(c1*1.1)-0.005 时 sealed+=1；
   score = round(sealed/final*100, 1)（final=0 时 None）；涨跌平家数按当日全市场 change_pct 计数
4) 只算缺的日子，落库 market_seal_stats；最多回看 460 天

【六、接口】
POST/GET /api/screen/start?date=YYYY-MM-DD -> 后台线程跑 run_screen，立即返回；同日重复点击不重复启动
GET /api/screen/status?date= -> {success,state:running|done|error,done,total,message,result?}
GET /api/screen?date= -> 同步返回该日结果（内存缓存 -> 本地库 -> 报错）
GET /api/screen/report?date= -> 独立 HTML 报告（Content-Type: text/html; charset=utf-8），无结果 404
GET /api/market-score?date= -> 只读、绝不触发扫描；默认日期=当前场次交易日，无结果则回退到最近一次有结果的日期；返回 {success,date,score,sealed,final}（无数据 score=null）
GET /api/market-history?days=45&start=&end= -> days 夹紧 5~120；默认窗口 120 天，给了 start 按 (今天-start)+30 扩展（上限 500）；返回 {success,days,start,end,rows,count,months}；rows 升序，字段 {date,up,down,flat,final,sealed,score,src,breadth_src,amount,amount_prev,amount_diff}；带 120 秒内存缓存；统计落后于最新日K时后台线程补算不阻塞

【七、前端】
1) 筛选面板：标题「动态选股 · 参数化扫描」；条件卡片三条（条件① 前一交易日(D-1) 首次涨停时间取反 → D-1 全天未触及涨停价；条件② (D 最高价 − D-1 收盘价) ÷ D-1 收盘价 > 0.09；条件③ 沪深主板 且 非 ST）；目标日期输入（默认最近交易日，自动跳周末节假日）；「🎯 开始扫描」；提示「首次扫描全市场约需 30 秒，同一日期结果会缓存，重复查询秒出。」
2) 结果区：元信息（数据所属交易日/前一交易日/全市场扫描暂停/耗时）-> 进度条「已扫描 N/M」-> 选股漏斗（全部沪深主板非ST / 条件② 盘中最高涨幅>9% / +条件① 昨日未涨停(入选) / 其中 封住涨停 / 其中 冲高未封 / 被条件①剔除(昨日涨停股)，底部封板率 xx.x%（sealed / final））-> 语义交叉校验卡片（D 涨停池 N 只 · D 炸板池 N 只 · D-1 涨停+炸板池 N 只；无冲突显示「✅ 价格法（最高价 ≥ 涨停价）与涨停池法结果完全一致，冲突 0 处」，有冲突列出股票）-> 三张子表切换（入选池 N / 冲高未封 N / 被条件①剔除 N）-> 明细表 10 列

   默认按「涨跌幅」升序；每列表头可点击排序（升降切换，数字列默认降序、文本列默认升序，空值恒排最后，未排序列显示 ⇅）；状态列 封板(红)/炸板(橙)/未封板(灰)；涨跌幅红涨绿跌，最高涨幅>=9.9% 加粗；点名称打开个股K线弹窗
4) 导出按钮「📥 导出 HTML 报告」
5) 页头行情评分卡片「今日行情评分 xx.x 分」：打开页面即请求 /api/market-score（不触发扫描）；颜色 >=70 红 / >=50 橙 / <50 绿 / 无数据 --；保留 1 位小数
6) 行情评分走势面板：说明（评分=当日封板率；涨跌家数=沪深京全A口径；成交额=沪深两市口径）；工具行 月份按钮 + 近30天/近60天/全部；摘要条「最新交易日 / 行情评分 / 上涨 / 下跌 / 成交额 / 较上一日 / 共 N 个交易日」；
   双轴图：左轴「评分」0~100 折线（橙色 #f39c12，smooth，宽3，connectNulls），右轴「家数」两组柱（上涨家数 rgba(231,76,60,.62)、下跌家数 rgba(46,204,113,.62)）；x 轴用 date.slice(5)；

【八、异常必须处理】非交易日报错并给最近可用日；历史不足报错；股票列表失败报错；单只取数失败不落暂存下次重试；日K缺 d2/d1/d 跳过该股；东财池失败主流程继续；入选池为0评分记0；所有价格比较减 0.005 容差；涨幅用比例(>0.09)比较；断点续传 flush 300；同日重复点击不重复启动

【九、验收测试（请自己跑并给出证据）】
