# 阿里云域名部署指南

> 把本地 `http://localhost:5000` 部署到你的阿里云域名，让公网可访问。
> 适用：阿里云 ECS / 轻量应用服务器（Ubuntu 22.04 / Debian 12）

---

## 一、部署前必读

### 1.1 你需要准备什么

| 项目 | 说明 | 是否已有 |
|------|------|---------|
| 域名 | 已在阿里云注册 | ✅ |
| 服务器 | 阿里云 ECS 或轻量应用服务器（≥2核2G） | ❓ |
| ICP 备案 | 服务器在**中国大陆**时**必须**备案 | ❓ |
| SSL 证书 | 阿里云可免费申请 | ❓ |

### 1.2 备案问题（最关键）

```
域名 → 解析到中国大陆服务器 → 未备案 = 80/443 端口被阿里云拦截 = 打不开
```

| 服务器位置 | 是否需要备案 | 建议 |
|-----------|-------------|------|
| 中国大陆（北京/杭州/深圳等） | **必须**（7–20 天，免费） | 长期运营选这个 |
| 中国香港 / 新加坡 | 不需要 | 想快速上线选这个 |

**备案路径**：阿里云控制台 → 备案 → 提交资料（需服务器已购买满 3 个月）

## 二、整体架构

```
用户浏览器
    │  https://你的域名
    ▼
阿里云 DNS 解析（A 记录 → 服务器公网 IP）
    │
    ▼
阿里云服务器（ECS）
    ├─ Nginx     监听 443，反向代理          ← deploy/nginx.conf
    │      │
    │      ▼ 127.0.0.1:5000
    └─ Flask     由 systemd 守护，开机自启     ← deploy/stock-popularity.service
           │
           ▼ 外网请求
      同花顺 / 东方财富 / 新浪 / 腾讯
```

## 三、部署步骤

### 步骤 1：购买并初始化服务器

1. 阿里云控制台 → 云服务器 ECS → 创建实例
2. 配置建议：**2 核 2G**、Ubuntu 22.04、系统盘 40G
3. **安全组放行端口**：22（SSH）、80（HTTP）、443（HTTPS）

### 步骤 2：上传代码

在你**本地 Windows** 上执行（把 IP 和路径换成你的）：

```powershell
# 用 scp 上传整个项目（排除 venv 和缓存）
scp -r "C:\Users\Administrator\Documents\ChatGPT\打卡小工具\stock-popularity" root@你的服务器IP:/opt/
```

或者用 `git`：

```bash
# 在服务器上
cd /opt
git clone https://github.com/你的用户名/stock-popularity.git
```

### 步骤 3：一键安装环境

```bash
ssh root@你的服务器IP
cd /opt/stock-popularity
sudo bash deploy/install.sh
```

脚本会自动：
- 安装 Python3 / Nginx / Node.js 22
- 建虚拟环境并装依赖
- 注册 systemd 服务并启动

### 步骤 4：配置 Nginx

```bash
# 1. 编辑配置，把 YOUR_DOMAIN 换成你的域名
sudo nano /opt/stock-popularity/deploy/nginx.conf

# 2. 复制到 Nginx
sudo cp /opt/stock-popularity/deploy/nginx.conf /etc/nginx/conf.d/stock-popularity.conf

# 3. 测试并重载
sudo nginx -t && sudo systemctl reload nginx
```

### 步骤 5：申请并配置 SSL 证书

1. 阿里云控制台 → 数字证书管理服务 → 免费证书 → 申请（绑定你的域名）
2. 下载 **Nginx 版**，得到 `.pem` 和 `.key` 两个文件
3. 上传到服务器：

```bash
sudo mkdir -p /etc/nginx/ssl
# 把证书上传到 /etc/nginx/ssl/YOUR_DOMAIN.pem 和 .key
sudo chmod 600 /etc/nginx/ssl/*
sudo systemctl reload nginx
```

### 步骤 6：配置域名解析

阿里云控制台 → 云解析 DNS → 你的域名 → 添加记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---------|---------|--------|-----|
| A | @ | 服务器公网 IP | 600 |
| A | www | 服务器公网 IP | 600 |

### 步骤 7：配置 hithink-finance CLI（题材热度功能需要）

```bash
# 安装 CLI
npm install -g @hithink/finance-cli   # 具体包名以官方为准

# 配置 API Key（用你自己的）
hithink-finance auth login

# 验证
hithink-finance auth status
```

> ⚠️ 题材热度功能依赖这个 CLI + API Key；其余功能（人气榜、个股详情、动态选股）不需要。

### 步骤 8：验证

```bash
# 本地验证后端
curl http://127.0.0.1:5000/api/trading-days?n=1

# 公网验证
curl https://你的域名/api/trading-days?n=1
```

浏览器打开 `https://你的域名` 应该能看到页面。

## 四、必踩的坑

### 坑 1：504 Gateway Timeout（最常见）

**现象**：人气榜能打开，但点「题材热度」等待一会儿报 504。

**原因**：题材热度首次要 **40–60 秒**，Nginx 默认 `proxy_read_timeout` 只有 60 秒。

**解决**：`deploy/nginx.conf` 里已经设为 `300s`，确认配置生效：

```bash
grep read_timeout /etc/nginx/conf.d/stock-popularity.conf
```

### 坑 2：题材热度报错但其他功能正常

**原因**：服务器没装 `hithink-finance` CLI，或 API Key 未配置。

**解决**：执行步骤 7，然后 `sudo systemctl restart stock-popularity`

### 坑 3：服务起不来

```bash
# 看日志
sudo journalctl -u stock-popularity -n 50
sudo tail -f /var/log/stock-popularity.log

# 常见原因：端口被占用 / 依赖没装全 / 权限不对
sudo lsof -i:5000
```

### 坑 4：改了代码没生效

```bash
sudo systemctl restart stock-popularity
```

> 注意：`serve.py` 关闭了自动重载（常驻服务不该开），所以改代码后**必须重启**。

### 坑 5：缓存文件写不进去

```bash
sudo chown -R www-data:www-data /opt/stock-popularity
```

（`www-data` 是 systemd 服务里指定的运行用户）

## 五、日常运维命令

```bash
# 服务管理
sudo systemctl status stock-popularity     # 查看状态
sudo systemctl restart stock-popularity    # 重启
sudo systemctl stop stock-popularity       # 停止
sudo journalctl -u stock-popularity -f     # 实时日志

# Nginx
sudo nginx -t                              # 测试配置
sudo systemctl reload nginx                # 重载

# 查看端口
sudo lsof -i:5000
ss -tlnp | grep 5000
```

### 更新代码

```bash
cd /opt/stock-popularity
git pull                      # 或重新 scp 上传
./venv/bin/pip install -r requirements.txt -q
sudo chown -R www-data:www-data .
sudo systemctl restart stock-popularity
```

## 六、可选：进一步加固

| 项目 | 说明 |
|------|------|
| 防火墙 | `ufw allow 22,80,443/tcp && ufw enable` |
| 访问限流 | Nginx `limit_req` 防止被刷 |
| 日志切割 | `logrotate` 防止日志撑爆磁盘 |
| 监控告警 | 阿里云云监控 + 拨测 |
| 数据库 | 如需多用户/历史数据，加 MySQL/Redis |
| 备案号 | 网站底部需挂 ICP 备案号（法规要求） |

## 七、文件清单

| 文件 | 用途 | 部署到 |
|------|------|--------|
| `deploy/install.sh` | 一键安装环境 | 服务器上执行 |
